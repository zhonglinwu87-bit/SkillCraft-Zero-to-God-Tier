# L3-15：产品发布作战计划 —— 五阶段发布法 +ORB（ORB：自有/租用/借用 渠道模型）渠道模型 + 三层更新策略

> 🎯 **学什么**：学会策划从内部测试到全量发布的五阶段发布流程——发布不是上线那一天的 1 秒钟，而是一条从 Phase 1 开始积累动量的坡道。用ORB（ORB：自有/租用/借用 渠道模型）渠道模型（自有/租用/借用）选择推广渠道，用三层更新分类（Major/Medium/Minor）给每个产品更新匹配正确的营销力度。核心洞察：最好的公司不是只发布一次——他们一次又一次地发布。每次新功能、每个改进、每个更新都是一次吸引注意力和激活用户的契机。
> 💡 **难易度**：⭐⭐ | ⏱️ **预计时间**：45 分钟

***

## 1. 课程概览

> 💡 **白话小课堂**：这个 Skill 就像一个**电影上映总策划**——很多人以为"发布"就是网站上线那一天的 1 秒钟，就像电影上映就是大屏幕亮起来的那一刻。但实际上，一部成功的电影在上映之前已经走了很长的路——先小范围内部试映（给朋友看）→ 修改 → 再试映（给影评人看）→ 积攒口碑 → 办首映礼 → 最后全国公映。产品发布也是一样——从内部测试→初步开放→扩大范围→正式上线→持续迭代，每个阶段都在积累"动量"（momentum），动量越滚越大，到正式发布的那天就已经不费吹灰之力。

> **本课的独特定位**——系统工程型 Skill：

| 特征 | 执行型 Skill | L3-15（本课） |
|------|------------|-------------|
| 粒度 | 单个操作（写一篇文章） | **系统工程（跨数月的多阶段发布）** |
| 时间跨度 | 即时 | **数周到数月** |
| 核心思维 | "做这件事" | **"这件事在第几阶段做？"** |
| 输出 | 一个产物 | **一份作战计划 + 检查清单** |

> 🔑 **核心秘诀**：ORB 框架的灵魂是——"一切最终都应该导回自有渠道"。抖音账号再火，平台一个算法调整，200 万粉丝的账号可能只剩 20 万曝光。你拿不到的（Rented）只是桥，你拥有的（Owned）才是家。

> ⚠️ **避坑指南**："发布=上线那一天"这个误解害了无数创业者。他们把全部精力和期待压在一天上——结果那天没多少人，团队士气崩了，产品也开始走下坡路。

## 2. 五阶段发布法详解

### 2.1 不是一天，是一条坡道

```
Phase 1: 内部发布（Internal Launch）
  时间：正式发布前 8-12 周
  目的：内部验证产品核心功能是否可用
  受众：创始人、团队成员、亲密朋友（10-20 人）
  动作：一对一邀请测试，面对面收集反馈
  产物：最原始的bug（程序缺陷） 列表 + 核心体验问题清单
  不要跳过的理由：连你自己团队都不用的产品，怎么让外人用？

Phase 2: Alpha 发布
  时间：正式发布前 6-8 周
  目的：首次让外部用户接触产品，验证需求假设
  受众：友好用户、早期支持者、行业熟人（50-100 人）
  动作：建立 Landing Page（Landing Page：落地页）+ 等待名单 + 手动邀请
  产物：用户行为数据 + 功能使用频率 +NPS（NPS：净推荐值）评分

Phase 3: Beta 发布
  时间：正式发布前 3-6 周
  目的：收集更广泛的反馈，修复高频问题
  受众：等待名单中的活跃用户（200-500 人）
  动作：公开邀请注册 + 建立用户社群（微信群/Slack/Discord） + 请 KOL（KOL：关键意见领袖）评测
  产物：规模化的bug（程序缺陷） 报告 + 用户评价 + 传播种子用户

Phase 4: Early Access（早期访问）
  时间：正式发布前 1-3 周
  目的：规模化验证 + 为全量发布积蓄动能
  受众：等待名单所有人 + 特定渠道用户（1000-5000 人）
  动作：提供优惠价格（"Early Bird"）+ 收集使用视频和评价
  产物：社会证明素材 + 真实用户案例 + 产品评测

Phase 5: 全量发布（General Availability）
  时间：正式发布日期
  目的：最大化发布动量
  受众：所有目标用户
  动作：同步所有ORB（ORB：自有/租用/借用 渠道模型）渠道 + 发布媒体报道 + 社交媒体推广
  产物：发布公告 + 媒体包 + 发布周活动
```

### 2.2 五阶段的"动量积累"原理

```
为什么不是 Phase 5 突然爆发？

Phase 1（内部）→ 0 外部动量（踩油门不挂档）
Phase 2（Alpha）→ 建立 Landing Page（Landing Page：落地页）+ 等待名单（第一个 Owned 资产）
Phase 3（Beta）→ 等待名单转化→微信群（第二个 Owned 资产） +KOL（KOL：关键意见领袖）评测（Borrowed）
Phase 4（Early Access）→ 口碑扩散 + 社会证明积累（动量可见增长）
Phase 5（全量）→ 所有积累的动量和渠道同时爆发

如果跳过 Phase 1-4，直接 Phase 5：
  → 零等待名单 → 零种子用户 → 零社会证明 → 零口碑
  → Phase 5 = 对着空房间喊"我发布啦！"→ 没有回音

如果做了 Phase 1-4：
  → Phase 5 那天你已经有了等待名单、微信群、公众号关注、首批评测
  → 所有积累在同一时刻爆发 → "怎么这么多人"的感觉
  → 而这个感觉本身就是社会证明——"为什么这么多人在抢？我也去看看"
```

## 3.ORB（ORB：自有/租用/借用 渠道模型）渠道模型

### 3.1 三种渠道的本质

```
Owned（自有渠道）— 你的房子
  定义：你完全拥有和控制的渠道
  例子：邮件列表、公众号、微信群、APP 推送、官网
  优势：永久拥有、不依赖算法、关系最深
  劣势：增长慢（需要自己建）
  角色：最终目的地——一切流量最终导回这里

Rented（租用渠道）— 你租的公寓
  定义：你使用但不拥有的平台渠道
  例子：抖音、小红书、微博、Twitter/X、LinkedIn
  优势：流量大、增长快、平台帮你匹配用户
  劣势：算法不可控、政策可变、账号可能被封
  角色：桥——把人从平台引流到你的 Owned 渠道

Borrowed（借用渠道）— 朋友家的客厅
  定义：临时借用他人的受众
  例子：KOL 评测、媒体报道、Podcast 嘉宾、联合推广
  优势：触达新人群、第三方信任背书
  劣势：一次性、不可持续、依赖对方配合
  角色：放大器——在 Owned + Rented 的基础上乘以 N 倍
```

### 3.2 ORB 的核心原则：一切导回 Owned

```
为什么？
  → Rented 的算法今天让你火明天让你凉——不可控
  → Borrowed 的 KOL（KOL：关键意见领袖）只能借一次——不可持续
  → 只有 Owned——邮件地址是你永久的资产

操作示例：
  在抖音发了一条爆款视频（Rented）
  → 视频结尾："关注公众号回复'工具包'免费领取"
  → 或者在评论区置顶："加我微信进交流群"
  
  上了 KOL 的评测（Borrowed）
  → KOL 介绍中放你的 Landing Page（Landing Page：落地页）链接
  → Landing Page（Landing Page：落地页）收集邮箱 → 进入你的邮件列表（Owned）
  
  所有 Rented 和 Borrowed 的流量，最终目的地 = Owned 渠道
```

## 4. 三层更新策略 —— 持续发布

### 4.1 不是所有的"更新"都值得发公告

```
Major Update（重大更新）— 营销力度：🔴🔴🔴
  定义：核心新功能、新集成、重大 UX 改版
  营销动作：邮件所有用户 + 博客文章 + 社交媒体 + 产品内公告 + Product Hunt
  示例：新增 Slack 集成、推出移动 App、全新 UI
  频率：每季度 1-2 次

Medium Update（中等更新）— 营销力度：🟡🟡
  定义：功能增强、较小的新功能、体验优化
  营销动作：产品内公告 + 社交媒体 + 更新日志
  示例：新增导出 PDF 功能、优化搜索速度、新增 3 个图表类型
  频率：每 2-3 周 1 次

Minor Update（小型更新）— 营销力度：🟢
  定义：Bug 修复、微小 UI 调整、后台优化
  营销动作：更新日志
  示例：修复一个罕见崩溃、按钮颜色从蓝变深蓝
  频率：随时

核心原则：营销力度 = 用户感知到的价值变化
  用户不关心按钮颜色变了 → Minor
  用户关心"哦我现在可以跟 Slack 打通了" → Major
```

### 4.2 Product Hunt（Product Hunt：产品发布社区）发布策略

```
发布前（3-6 个月开始积累）：
  → 注册 Product Hunt（Product Hunt：产品发布社区）账号（用创始人真实姓名）
  → 活跃参与社区（给其他人点赞、评论）
  → 建立 PH 上的关注者基础（让发布时有人第一时间看到）

发布前 1 周：
  → 确认发布者身份（最好是创始人、CEO 或产品负责人）
  → 产品页面全部填满：图标、标题、描述、首张图、视频
  → 提前通知你的社群"我们下周在 PH 上发布"

发布当天：
  → 第一时间在所有 Owned 渠道通知"我们在 PH 上线了"
  → 不要买票或买评论（PH 能检测并封禁）
  → 创始人亲自回复每一条评论
  → 持续活跃到当天结束

发布后：
  → 发布结果通告（排名、获得的评论数）
  → 分析用户反馈——PH 评论往往是最真实的产品反馈
  → 将获得的新用户导入邮件序列
```

## 5. 结构拆解：系统工程型 Skill 模板

```markdown
## 系统工程型 Skill 模板

→ 核心 = 分阶段积累动量 + 渠道矩阵部署
→ 关键设计 = 阶段划分 + 渠道角色分配 + 更新分级

### 通用结构

## Launch Phases（发布阶段）

Borrowed: 定义 — 角色 — 局限

Major / Medium / Minor
```

**什么时候用系统工程型？** → 当任务不是单点操作而是一个需要多阶段协调的系统工程时：产品发布、活动策划、迁移计划——任何"怎么从现在走到目标"的规划类任务。

## 6. 电商案例：智能书法套装天猫新品上市五阶段作战计划

> 🛒 **实战案例**：「墨研」书法用品品牌准备在天猫旗舰店推出新品"便携智能书法练习套装"（智能毛笔+水写布+App AI 点评课程，售价 ¥368）。店主在书法圈有一定基础——公众号 850 关注、3 个书法交流微信群合计 420 人、行业人脉可联系到 3 位书法博主（Borrowed）。品牌此前在天猫只有一个"墨研文房"旗舰店，月销约 ¥12,000（毛笔+宣纸+砚台常规品），这是第一次做系统性新品发布。
>
> **用 product-launch Skill 制定五阶段作战计划**：
>
> | 阶段 | 时间 | 受众 | ORB 动作 | 积累的资产 | 核心指标 |
> |------|------|------|---------|-----------|---------|
> | **Phase 1 内部发布** | 8/1-8/14（发布前 8 周） | 团队 3 人 + 邀请 8 位书法老师朋友 | Owned：面对面测试，逐一记录"哪里用着别扭""学生最常问什么" | 核心体验问题清单 23 条（App 卡顿 3 处、水写布寿命不足预期、笔杆太滑） | 23 条问题全部在 Phase 2 前修复 |
> | **Phase 2 Alpha** | 8/15-8/28（发布前 6 周） | 50 位微信群活跃用户（从 420 人中精选） | Owned：微信群限额内测报名（68 人报名，选 50 人）+ Landing Page（Landing Page：落地页）等待名单开放 | 等待名单 320 人报名 |NPS（NPS：净推荐值）48 → 修复痛点后升至 72 |
> | **Phase 3 Beta** | 8/29-9/11（发布前 3 周） | 200 位等待名单用户 + 3 位书法博主 | Owned：微信社群运营（每日 1 位用户分享练习打卡）+ Borrowed：3 位博主录制"用墨研练习了一个月，看看我的进步"视频评测 | 微信社群 420 人 + 3 篇博主视频评测（小红书+抖音合计播放 8.2 万） | 博主视频评论中自发出现"在哪买""什么时候上"共 340+ 条 |
> | **Phase 4 Early Access** | 9/12-9/25（发布前 1 周） | 等待名单 560 人 | Owned：公众号 3 篇预热文（产品故事+博主评测合集+用户打卡合集）+ Early Bird（早鸟优惠）¥298（限前 100 名） | 100 笔 Early Bird（早鸟优惠）订单（24 小时售罄）+ 首批 58 条用户评价+实拍视频 | 预售转化率 17.9%（560 人名单 → 100 笔） |
> | **Phase 5 全量发布** | 9/26（发布日） | 所有渠道爆发 | Owned：公众号推送+微信群全员通告+天猫旗舰店正式上架；Rented：小红书/抖音同步发布博主演素材+用户 UGC；Borrowed：3 位博主当天发"终于上线了"动态 | 天猫旗舰店新品上架当日 | 首日销量 187 单（含预售 100 单），首日 GMV（GMV：商品交易总额）¥68,816 |

> **发布日积累的全部资产**：等待名单 560 人 + 微信群 420 人 + 公众号 850 关注 + 3 篇博主视频评测（总播放 12.5 万）+ 58 条真实用户评价+实拍视频 + 100 笔 Early Bird（早鸟优惠）订单的社会证明。发布日当天所有渠道同步爆发——**天猫首日销量 187 单、GMV ¥68,816，相当于品牌此前月 GMV（GMV：商品交易总额） 的 5.7 倍在一天内完成**。

> **发布后 30 天持续运营**：
> - 首月累计销量 1,240 单、GMV ¥456,320（远超此前月均 ¥12,000）
> - 天猫旗舰店"智能书法练习"关键词搜索排名从第 0 → 第 2 名
> - 58 条 Early Bird（早鸟优惠）评价中 52 条为 5 星——首波评价质量决定后续转化

> 🔑 **启示**：正式上线那天不是"开始"，而是"收网"。Phase 1-4 用 8 周时间织了一张网——产品问题修复、种子用户积累、KOL 评测口碑、Early Bird（早鸟优惠）销售与社会证明、等待名单蓄水。到 9 月 26 日，你需要的不是"求大家来买"，而是"通知大家买得到"。一张收得好的网，首日 GMV（GMV：商品交易总额）可以是之前月 GMV（GMV：商品交易总额） 的 5.7 倍。

## 8. 答案

<details>
<summary>点击查看答案</summary>

**Q1**：**C** ——KOL（KOL：关键意见领袖）评测属于 Borrowed（借用他人受众）。A 和 B 是 Owned（自有），D 是 Rented（租用平台）。

**Q2**：参考答案——Rented 渠道风险：算法调整导致曝光断崖下跌、平台政策变化限流/封禁、竞争推高获客成本、粉丝是平台用户非你真正拥有的联系人。导回示例：抖音爆款视频→评论置顶"加微信进交流群"或"关注公众号回复 XX 领取资料"。

**Q3**：参考答案——Phase 1 是内部验证（10-20 人，验证"这个产品能用吗"），Phase 4 是规模化验证+积蓄动能（1000-5000 人，验证"这个产品在市场上有吸引力吗"并积累社会证明）。规模不同、目标不同、产物不同。

**Q4**：参考答案——"发布=上线那一天"忽略了发布是一个动量积累的持续过程。从 Phase 1 开始，每个阶段都在积累资产和动能，Phase 5 是全量收网。如果跳过 Phase 1-4 直奔 Phase 5，就像对着空房间宣布发布——没有积累、没有动能、没有回音。

**Q5**：**B** —— 新增 Slack 集成是 Major update，应匹配 Major 级营销。A/D 是 Minor，C 也是 Minor。

**Q6**：参考答案——发布前 3-6 月：活跃参与 PH 社区、建立关注者基础。发布前 1 周：完善产品页面、通知社群。发布当天：所有 Owned 渠道同步通知、创始人亲自回复每条评论、持续活跃到当天结束。
