# L3-08：定价策略设计 —— 五效应工具箱 + 三层方案框架 + 价值度量

> 🎯 **学什么**：学会用五种定价心理学效应设计价格点、用 Good-Better-Best（入门-主力-高端 三层方案）三层方案框架让用户从"买不买"变成"买哪个"、用正确的 Value Metric（价值度量标准）（价值度量标准）确保涨价有理有据。核心洞察：定价不是数学题（成本+利润=价格），而是心理题——"他看到价格后觉得哪个最划算？"三层方案的精髓：最贵的方案不是为了卖，是为了让中间方案"看起来便宜"。
> 💡 **难易度**：⭐⭐ | ⏱️ **预计时间**：40 分钟

***

## 1. 课程概览

> 💡 **白话小课堂**：这个 Skill 就像一个**菜单设计师**——你去餐厅，服务员递给你菜单，你发现只有三个套餐：小份 38 元（看着不够吃）、中份 58 元（刚好、最划算）、大份 98 元（太多了没人点但其实是有意放上去的）。你会毫不犹豫选中份——这正是餐厅希望你选的。大份 98 元的存在不是为了卖，是为了让 58 元"看起来便宜"——这就是定价心理学。

> **本课的独特定位**——心理学工具箱型 Skill：

| 特征 | L3-05（转化文案） | L3-08（本课） |
|------|-----------------|-------------|
| 核心 | 文字怎么写 | **价格怎么定** |
| 工具箱 | 五条原则 + 页面结构 | **五种效应 + 三层方案 + 价值度量** |
| 核心难题 | 文案顺序 | **Value Metric（价值度量标准） 选择——选错了后面全错** |

> 🔑 **核心秘诀**：选对 Value Metric（价值度量标准），定价就成功了一半。如果你的产品价值跟使用量正相关，但你按"用户数"收费：用户 A 用 100 次和用户 B 用 1 次付一样的钱——用户 A 觉得"太划算了"（你亏了），用户 B 觉得"太贵了"（他跑了）。正确的 Value Metric（价值度量标准） 应该跟使用量或获取的价值成正比——用得多付得多，用得少付得少，谁都服气。

> ⚠️ **避坑指南**：魅力定价（Charm Pricing（魅力定价法））——$49 和 $50 虽然只差 1 块钱，但转化率差异可能高达 15-20%。但也别滥用——高端品牌用整数（$100 而非 $99）传递"品质感"，平价品牌用 9 结尾（$99）传递"划算感"。选错了数字暗示，价格传达的情感就反了。

## 2. 五种定价心理学效应详解

### 2.1 效应工具箱

```
效应 1: Anchoring（锚定效应）
  机制：先展示最高价格，让目标价格显得便宜
  例子：你走进奢侈品店，先看到一件 3 万的外套（锚），
        再看到 8000 的包，8000"好便宜"
        如果没有那件 3 万的外套做锚，8000 的包你还是觉得贵
  定价应用：把最贵方案（Enterprise）放在最左边第一个展示
         → 用户先看到 ¥999/月
         → 再看 ¥299/月的主力方案 → "好划算"

效应 2: Decoy Effect（诱饵效应）（诱饵效应）
  机制：加一个明显不划算的方案，让目标方案更吸引人
  例子：电影院小份爆米花 18 元、中份 30 元、大份 32 元
        大份 32 元是"诱饵"——它的存在让中份 30 元"不划算"
        所以大多数人买了大份
        没有大份做参照，中份 30 元就显得贵了
  定价应用：设计一个"故意不划算"的方案来推主力方案
         → 例如：Starter ¥49（功能少）、Pro ¥79（功能全）、
                 Ultra ¥299（功能多但价格是 Pro 的 3.8 倍）
         → Ultra 作为诱饵让 Pro 显得"超级划算"

效应 3: Center Stage（居中效应）（居中效应）
  机制：3 个方案中，大多数人选中间那个
  例子：任何"基础/标准/高级"三层方案中，
        60-70% 的用户选择中间方案
        → 不是因为中间方案本身最好
        → 而是因为"中间"在心理上 = "安全"
  定价应用：主力方案（你最想卖的那个）放在中间位置
         → 并用视觉突出（高亮/推荐标签/"最受欢迎"）

效应 4: Charm Pricing（魅力定价法）（魅力定价）
  机制：以 9 或 99 结尾的价格看起来更便宜
  例子：$49 vs $50——$49 看起来"四十多"，$50 看起来"五十块"
        虽然只差 1 块钱，但转化率差异可达 15-20%
  定价应用：平价品牌用 9 结尾（¥99 传递"划算"）
         → 高端品牌用整数（¥100 传递"品质感"和"不打折的自信"）
         → 选错数字暗示 → 价格传达的情感就反了

效应 5: Price-Quality Heuristic（价格-质量关联效应）（价格-质量关联）
  机制：高价自动暗示高质量
  例子：一瓶红酒标价 ¥200 vs ¥50
        → 同一瓶酒，标 ¥200 时人们觉得"更好喝"
        → 不是酒不同，是价格改变了预期
  定价应用：如果你定位高端→不要怕定高价
         → 低价反而可能让目标用户觉得"这么便宜能好到哪去？"
         → 高价 = 你在用价格向用户说"我是最好的"
```

### 2.2 什么时候不该用哪个效应？

```
不该用 Charm Pricing（魅力定价法）（¥99）的场景：
  → 高端奢侈品（¥99 让产品显得廉价）
  →B2B（B2B：企业对企业商业模式）企业级产品（¥9999/年 比 ¥9999.99/年 更专业）
  → 价格本身就是品牌信号的产品

不该用诱饵效应的场景：
  → 只有 2 个方案时（需要至少 3 个方案才能制造诱饵）
  → 诱饵方案太荒谬时（用户会觉得你在耍他）

不该用锚定效应的场景：
  → 用户已经知道市场价格时（锚定失效——他们有自己的锚）
  → 锚太高时（¥99,999 的锚对于 ¥99 的产品=完全无用）
```

## 3. 三层方案框架（Good-Better-Best）

### 3.1 为什么是三层而不是两层或四层？

```
两层方案的问题：
  → 用户只能"买不买"——非黑即白
  → 用户的纠结：这个价格值不值？
  → 没有参照物可以对比

三层方案的魔力：
  → 用户从"买不买"变成"买哪个"
  → 用户的纠结：哪个方案最适合我？
  → Starter 和 Enterprise 的存在就是为了定位 Professional

四层方案的问题：
  → 选择困难复发——4 个方案 = 决策难度翻倍
  → 每一层之间的差异化变得模糊
  → 用户会问"Starter+ 和 Professional 到底有什么区别？"
```

### 3.2 三层方案的各自角色

```
Starter（入门方案）—— 降低门槛
  定价策略：低价，让用户"试试水不亏"
  设计目标：不是让用户永远用这个方案，而是让他先进门
  关键：功能刚好够让用户看到产品价值
  心理学角色：让 Professional 看起来"升级很值"
  示例：¥49/月，基础功能，1 个项目，1GB 存储

Professional（主力方案）—— 你的核心产品
  定价策略：最佳性价比——设计为"最划算"
  设计目标：让 60-70% 的用户首选这个方案
  关键：功能比 Starter 多很多，价格只加了一点
  心理学角色：居中效应 + 诱饵效应（Enterprise 做诱饵）
  示例：¥79/月，全部功能，10 个项目，50GB 存储 ← 加"最受欢迎"标签

Enterprise（高端方案）—— 充当品牌天花板
  定价策略：高价——不是为了卖它，是为了让它做锚
  设计目标：1）让 Professional 显得划算；2）万一有人买更好
  关键：功能比 Professional 多一点，但价格翻几倍
  心理学角色：锚定效应（让你先看这个）+ 诱饵效应
  示例：¥299/月，全部功能 + 专属支持，无限项目，1TB 存储
```

### 3.3 一个方案 vs 三个方案——用户心理的转变

```
一个方案（¥299 买 30 节摄影课）：
  想试水的人：「299 太贵了，不敢买」→ 流失
  想深入学的人：「299 太便宜了，能学到东西吗？」→ 流失
  想要 VIP 的人：「没有更多服务选项」→ 流失
  三种人都纠结"买还是不买" → 都走了

三个方案：
  Starter（¥99 / 10 节课 / 基础）：
    → 想试水的人：「99 试试水不亏」→ 买了
  Professional（¥299 / 30 节课 / 含练习批改）：
    → 想深入学的人：「比 Starter 多 20 节课只多 ¥200，划算」→ 买了
  Enterprise（¥899 / 30 节课 + 1v1 辅导 / 大师班）：
    → 想要 VIP 的人：「比 Professional 多 ¥600 但有 1v1，值得」→ 买了

核心心理转变：从"买不买"的纠结 → "买哪个"的决策
"买不买"需要说服自己掏钱
"买哪个"只需要比较方案之间的差异
后者容易得多
```

## 4. Value Metric（价值度量标准） —— 定价中最关键的设计决策

### 4.1 什么是 Value Metric（价值度量标准）？

Value Metric（价值度量标准） = 你按什么维度向用户收费。这是定价 Skill 中最容易被忽视但最关键的设计决策。

```
六种常见的 Value Metric（价值度量标准）：

1. 按用户数（Per Seat）：每个用户付一份钱
   → 适合：协作工具（Notion/Slack/CRM）
   → 逻辑：团队越大获得的价值越大

2. 按使用量（Per Usage）：用多少付多少
   → 适合：API 服务、云存储、短信平台
   → 逻辑：用得多 = 获得价值多 = 应该多付

3. 按功能（Per Feature）：功能越多价格越高
   → 适合：工具类 SaaS（如设计工具）
   → 逻辑：Pro 用户需要的功能更高级

4. 按记录数（Per Record）：按数据条数收费
   → 适合：CRM、邮件营销工具
   → 逻辑：管理更多客户 = 获得更多价值

5. 按交易额（Per Transaction）：按成交额抽成
   → 适合：电商平台、支付工具
   → 逻辑：你的收入跟我的平台挂钩

6. 固定费率（Flat Rate）：一个价格全包
   → 适合：简单工具、个人产品
   → 逻辑：功能简单，不需要差异化收费
```

### 4.2 Value Metric（价值度量标准） 选错了会怎样？

```
案例：一个CRM（CRM：客户关系管理系统）产品按"客户记录数"收费

用户 A：管理 10,000 条客户记录，每天用 CRM 处理销售流程 → 付 ¥999/月
用户 B：管理 50 条客户记录，每天用 CRM 处理销售流程 → 付 ¥49/月

问题：用户 A 和用户 B 从 CRM 获得的价值几乎一样
     但用户 A 付了 20 倍的价格——因为他客户多？
     这不公平！用户 A 会觉得被"惩罚"了

正确的 Value Metric（价值度量标准）：按"用户数"收费
  → 销售团队 5 人 = ¥299/月
  → 销售团队 50 人 = ¥2990/月
  → 逻辑：团队规模 ≈ 从 CRM 中获得的价值
  → 跟客户记录数无关——你们公司客户多不代表你应该付更多

关键原则：Value Metric（价值度量标准） 应该跟用户获得的"价值"成正比，
          而不是跟某个"碰巧能计数的东西"挂钩。
```

## 6. 电商案例：新品玻尿酸面膜的五效应定价决策

> 🛒 **实战案例**：天猫「肌研日记」护肤品牌准备推出一款玻尿酸面膜（5 片装），生产成本 ¥18/盒。竞品价格带横跨 ¥29-129，团队在定价上有严重分歧——运营经理想定 ¥49 走量，品牌经理想定 ¥89 走品质路线，老板想定 ¥69 走中间。三个人谁也说服不了谁——因为都没用数据+心理学框架，全靠"我觉得"。
>
> **用 baoyu-pricing-strategy 工具箱决策**：
> 1. 输入成本 ¥18、竞品价格带 ¥29-129、目标毛利率 65%、目标客群画像（22-35 岁女性/二三线城市/月护肤品预算 ¥100-300）
> 2. 五效应分析：
>    - 锚定（先展示 ¥89 版本 → 再推 ¥69 主力款）：品牌经理想定的 ¥89 不是废案——把它变成"锚定款"放在页面最左边，让 ¥69 看起便宜
>    - 折中（¥49/69/89 三档中间为推荐）：中间的心理安全感让大多数人选 ¥69
>    - 诱饵（虚拟 ¥79 低配版——5 片装无赠品，"故意不划算"来推 ¥69 带赠品款）
>    - 心理账户（"每天不到 ¥3 的护肤投资——比一杯奶茶还便宜"）：把 ¥69 除以 5 次使用= ¥13.8/次，降维到"一杯奶茶钱"
>    - 损失厌恶（"首周下单送 3 片试用装——错过首周，赠品下线"）：不买=损失赠品
> 3. Skill 输出三层方案：
>    - 引流款 ¥39（2 片体验装）——低门槛让新客试水
>    - 主力款 ¥69（5 片装+送 3 片试用装）——推荐标签+"最划算"
>    - 利润款 ¥99（10 片礼盒装）——锚定效应，让 ¥69 显得便宜
>
> **效果**：
> - 采用 ¥69 主力款 + ¥89 锚定款 + ¥99 利润款的组合策略
> - 首周销量 4,200 盒，客单价 ¥71（含组合购买）
> - 比直接定 ¥49 多出 ¥92,000 毛利（首周对比测算：¥49 × 4,800 盒预估 vs 实际 ¥71 × 4,200 盒）
> - 锚定效应使 ¥89 款的展示让 ¥69 款"显得便宜"，加购率提高 31%
> - ¥39 引流款贡献了 28% 的新客首次购买，其中 34% 在 30 天内复购了 ¥69 主力款

> 🔑 **启示**：定价不是算成本加利润，是操控用户的"参照系"。让用户觉得便宜比实际便宜更重要——¥69 旁边的 ¥89 和 ¥99 就是最好的销售员。品牌经理想定 ¥89 不是错了——是把角色搞错了：¥89 不应该当主力款，应该当锚定款。同一个价格，放在不同位置，效果天壤之别。

---

## 8. 答案

<details>
<summary>点击查看答案</summary>

**Q1**：**B** —— 诱饵效应。大份 32 元是"诱饵"，它的存在让中份 30 元（目标方案）看起来"只多花 2 元就能翻倍"——实际上电影院希望你买大份。没有大份做参照，中份 30 元就显得贵了。

**Q2**：参考答案——Value Metric（价值度量标准） 决定了"谁付多少钱"的公平性。按用户数收费的问题：用户 A（用 100 次）和用户 B（用 1 次）付一样的钱——用户 A 觉得"太划算了"（你亏了），用户 B 觉得"太贵了"（他跑了）。正确的 Value Metric（价值度量标准） 应该跟使用量或获取的价值成正比。Value Metric（价值度量标准） 一旦选错，价格再调都是错的。

**Q3**：**C** —— Professional 是核心方案，设计为"看起来最划算"，目的是让大多数用户的首选就是它。Enterprise（D）是锚定高端的，Starter（A/B）是降低门槛吸引试水的。

**Q4**：参考答案——核心心理转变从"买不买"变成"买哪个"。一个方案下三种人都纠结"买还是不买"——想试水的觉得贵、想深入学的觉得便宜不敢信、要 VIP 的觉得没得选。三个方案下每个人都能找到匹配自己的位置，不再纠结"值不值"而是"哪个最适合我"。

**Q5**：**B** —— 整数定价（100/300/900）传递"品质感"和"不打折的自信"，适合高端品牌。A 选项用 9 结尾（魅力定价）传递"划算感"，适合平价品牌。

**Q6**：**A** —— 按用户数（座位数）收费是 CRM 品类最合理的 Value Metric（价值度量标准）。销售团队的价值跟"有多少销售用 CRM"成正比。按使用量（B）会导致客户为了避免费用而少记录；按功能（C）是第二层维度。

**Q7**：参考答案——以视频会员 App 为例，分析须覆盖五种效应。见课程内容。
