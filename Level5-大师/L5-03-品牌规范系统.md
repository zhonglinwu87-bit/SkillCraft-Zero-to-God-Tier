# L5-03：品牌规范系统 —— 一键生成完整品牌VI手册

> 🎯 **学什么**：用 AI 把品牌规范变成可执行的代码级规则——颜色精确到 HEX 值、字体精确到字重、Logo 间距精确到像素。核心洞察：品牌规范不是「参考」，是「法律」——必须是精确的、不容商量的约束。模糊的描述（「比较深的蓝色」）导致每次 AI 输出的「蓝色」都略有不同，品牌就碎片化了。最好的品牌规范不是 10 页文字说明，而是每条规则配一个正确示例 + 一个错误示例——AI 极其擅长对比学习。
> 💡 **难易度**：⭐⭐⭐ | ⏱️ **预计时间**：35 分钟

***

## 1. 课程概览

> 💡 **白话小课堂**：想象你是麦当劳的老板。全国几千家店，你怎么保证每家店的招牌颜色、店员服装、薯条包装、广告语气都一模一样？靠的就是一本「品牌规范手册」——里面精确地写了：招牌必须用 PANTONE 186C（那个特定的红色）、M 字拱门的高度和宽度比例、薯条包装纸的黄色色值。

## 2. 品牌规范的五项核心组成

### 2.1 品牌系统全景

```
品牌规范系统包含五个维度：

1. Color Palette（颜色调色板）
   → 主色（品牌核心色，占视觉面积 60%）
   → 辅助色（陪衬主色，占 30%）
   → 功能色（成功绿/警告黄/错误红/信息蓝，占 10%）
   → 每个颜色精确到 HEX + RGB + HSL（不要只给 HEX——不同场景需要不同格式）

2. Typography（字体系统）
   → 标题字体（H1-H6 的字号、字重、行高、字间距）
   → 正文字体（字号 16px+，行高 1.5-1.75）
   → 代码/数据字体（等宽字体如 JetBrains Mono）
   → 字号比例系统（如 Major Third 1.25x 或 Perfect Fourth 1.333x）

3. Logo Usage（Logo 使用规则）
   → 最小尺寸（低于多少像素不能使用 Logo）
   → 安全间距（Logo 周围至少留多少像素空白）
   → 变体规则（深色背景用反白版本、最小尺寸用简化版本）
   → 禁止行为（拉伸、旋转、加阴影、改颜色）

4. Imagery（图片/插图风格）
   → 摄影风格（产品白底图 vs 场景使用图 vs 人物情绪图）
   → 插图规范（扁平 vs 3D、线条粗细、配色限制）
   → 图标体系（线性 vs 填充、圆角大小、网格基准 24×24）

5. Voice & Tone（文案语调）
   → 用词风格（专业术语 vs 口语化、第一人称 vs 第三人称）
   → 句式长度（标题 ≤ 8 字，正文每句 ≤ 25 字）
   → 情感基调（温暖/专业/幽默/权威）
   → 禁止用词（行业黑话、网络流行语、攻击性词汇）
```

### 2.2 为什么必须精确而非模糊

```
模糊规范的问题：
  ✗ 「我们比较喜欢蓝色」→ AI 每次选的蓝色都略有不同
     → 有的偏紫的蓝、有的偏绿的蓝、有的偏灰的蓝
     → 最终品牌物料之间颜色不统一
     → 品牌建设的本质是「重复产生记忆」——如果每次颜色都不一样，就无法建立视觉记忆

精确规范的解决方案：
  ✓ 主色：#1E40AF（RGB 30, 64, 175）
  ✓ 辅助色：#3B82F6（RGB 59, 130, 246）
  ✓ 强调色：#F59E0B（RGB 245, 158, 11）
  → AI 在任何场景下都输出完全一致的颜色
  → 所有物料「一家人」的视觉感受

精确到什么程度？
  → 颜色：HEX 值 + RGB + 使用场景（主色用于标题和按钮，辅助色用于背景和分隔线）
  → 字体：字体名 + fallback 链 + 字号 + 字重 + 行高（如 H1: Playfair Display Bold 48px/1.2）
  → 间距：基于 8px 基础单位的倍数系统（4/8/16/24/32/48/64px）
```

## 3. 品牌一致性的三个层次

### 3.1 三层递进

```
Level 1：视觉一致（Visual Consistency）——最低要求
  → 颜色用对了、字体用对了、Logo 放对了
  → 「看起来是同一个品牌」
  → 这是品牌建设的门槛——达不到这个层次就不是品牌

Level 2：语调一致（Tonal Consistency）
  → 所有文案读起来像同一个人写的
  → 同样的用词风格、句式节奏、情感温度
  → 「听起来是同一个品牌」
  → 比如：苹果的文案永远简洁自信（「iPhone. 强得很。」）
         小米的文案永远亲切直接（「永远相信美好的事情即将发生」）

Level 3：体验一致（Experiential Consistency）——最高境界
  → 用户不仅在视觉和语调上认出品牌
  → 在情感体验层面也感受到一致
  → 「感觉到的是同一个品牌」
  → 比如：去苹果店的体验（极简空间 + 木桌 + 产品随意摆放让你摸）
         和去小米店的体验（简洁但更亲民、产品密集展示）
  → 这是最难量化但品牌溢价最高的层次
```

### 3.2 三层在企业中的应用

```
大多数小品牌/创业公司：停留在 Level 1（甚至 Level 1 都不完整）
  → Logo 有了，但颜色经常变、字体每次不一样

成熟中型品牌：Level 1 稳固 + Level 2 建立中
  → 有完整品牌手册、所有物料统一、开始有品牌语调意识

顶级品牌：Level 1-3 全覆盖
  → 不仅有手册，还有品牌审核流程
  → 每个对外输出都经过品牌合规检查
  → 用户能从任何触点感受到一致的品牌体验
```

## 4. 示例为王：AI 时代的品牌规范写法

### 4.1 为什么示例比文字更有效

```
抽象规则的问题：
  「标题要有力量感」→ AI 不理解「力量感」是什么
  结果：AI 可能写出夸张的感叹句，也可能写出冰冷的术语

示例规则的优势：
  规则：「标题要有力量感」
  正确示例 ✓：「省 30 小时/月——自动报表帮你搞定」
  错误示例 ✗：「我们的产品可以帮助您节省大量的工作时间」
  
  AI 通过对比学习：
    → 学到了「力量感」= 具体数字 + 动词 + 简洁
    → 学到了「没力量」= 模糊形容词 + 长句式 + 被动语态
    → 比 10 页文字说明效果更好
```

### 4.2 品牌文案语调规则示例

以高端茶叶品牌「茶颜山房」为例：

```
规则 1：用词风格——东方、沉稳、有文化底蕴，避免网络流行语
  ✓ 「古树春芽·一盏入心」
  ✗ 「这个茶绝绝子好喝」

规则 2：句式长度——标题 ≤ 8 字，正文每句 ≤ 25 字
  ✓ 「三百年古树，一叶一春秋」
  ✗ 「我们这款茶是从具有三百年历史的古老茶树上面采摘下来的春茶芽头经过传统手工工艺精心制作而成的」

规则 3：情感基调——传递「宁静、敬畏、珍惜」，避免喧闹和紧迫感
  ✓ 「限量 300 份，静待知音」
  ✗ 「最后 3 天！再不买就没了！」

规则 4：数字使用——用中文数字传递文化感，避免阿拉伯数字的商务感
  ✓ 「三百年」「四季」「一盏」
  ✗ 「300年」「4季」「1杯」
```

### 4.3 品牌规范的文件组织

```
brand-guidelines 的文件结构设计体现了「渐进式披露」原则：

SKILL.md（≤ 500 行）
  → 品牌核心原则（5 句话以内）
  → 检查清单（AI 生成任何东西前必须过一遍）
  → 快速参考（最常用的 3-5 个色值 + 2 个字体）

references/（按需加载）
  → brand-colors.json —— 完整调色板（所有色值 + 使用场景）
  → brand-typography.json —— 完整字体层级（所有字号/字重/行高配置）
  → brand-voice.md —— 文案语调详细规范 + 正确/错误示例
  → brand-assets.md —— Logo 使用规则 + 安全间距 + 变体说明

为什么这样设计？
  → 不把全部规范写在 SKILL.md 里（每次对话都加载 = 浪费 token）
  → AI 在处理具体任务时才按需读取对应的 reference 文件
  → 类比：SKILL.md 是「品牌速查卡」，references/ 是「品牌完整手册」
```

## 5. 结构拆解：品牌规范型 Skill 模板

```markdown
## 品牌规范型 Skill 模板

### 核心特征
→ 管理对象 = 品牌视觉和语调的一致性
→ 核心原则 = 精确 > 模糊 + 示例 > 文字 + 法律 > 参考
→ 关键设计 = 五维组成 + 三层一致性 + 渐进式披露文件组织

### 通用结构

## Brand Components（五项组成）
1. Color Palette（HEX + RGB + 使用场景）
2. Typography（字体名 + fallback + 字号/字重/行高）
3. Logo Usage（最小尺寸 + 安全间距 + 变体 + 禁止行为）
4. Imagery（摄影/插图/图标风格规范）
5. Voice & Tone（用词 + 句式 + 情感基调 + 禁止词）

## Consistency Levels（三层一致性）
- Level 1: Visual → 看起来是同一个品牌
- Level 2: Tonal → 听起来是同一个品牌
- Level 3: Experiential → 感觉到的是同一个品牌

## Example-First（示例为王）
每条规则 = 1 条说明 + 1 个正确示例 + 1 个错误示例
AI 通过对比学习理解规则的「精神」而非「字面」

## File Architecture（文件组织）
SKILL.md ≤ 500 行（原则 + 检查清单 + 快速参考）
references/ 按需加载（完整色值/字体/文案/Logo 规范）
```

## 6. 电商案例：天猫店铺全套视觉规范生成

某新锐宠物食品品牌「尾巴生活」（主营冻干生骨肉猫粮，天猫旗舰店）因品类竞争激烈——天猫猫粮品类 Top 20 品牌中 19 家使用暖色调（橙/黄/棕）——品牌方需要用差异化的视觉规范在货架中建立辨识度。

传统找品牌设计公司需要 2-3 周、报价 ¥3-5 万。创业团队预算有限，用 brand-guidelines 1 天内完成全套 VI 规范。

**Step 1：确定差异化关键词**
「冷静、科学、专业、宠物营养学」——避开全行业的「温暖/自然/家庭」路线

**Step 2：定义颜色调色板（精确到 HEX）**
- 主色：#2D4A7A（冷静蓝——传达科学与信任，用于店铺首页背景和主按钮）
- 辅助色：#F5F0E8（暖象牙白——平衡蓝色的冷感，用于卡片底色和详情页背景）
- 强调色：#C8963E（铜金色——暗示高品质，用于价格标签和「热卖」角标）
- 功能色：成功 #5D9B6C / 警告 #E8A840 / 错误 #C75B5B

**Step 3：定义字体系统**
- 标题：DM Serif Display（衬线体传递品质感，替代宠物行业常用的圆体）
- 正文：Noto Sans SC Regular 15px/1.6（保证可读性）
- 字号比例：Major Third（1.25x）——14/18/23/28/35/44px

**Step 4：定义语调规范（示例为王）**
- 规则 1：用「营养学」语言而非「爱宠」语言
  ✓ 「≥42% 粗蛋白 · 0 谷物 · 0 诱食剂」
  ✗ 「毛孩子最爱吃的粮粮~」
- 规则 2：数字先于形容词——一切卖点用百分比和克数支撑
  ✓ 「实测消化率 92.3%」
  ✗ 「吸收特别好」
- 规则 3：不叫「主人」、不叫「铲屎官」——称「家长」（专业化而非萌化）

**效果**：
- 品牌规范搭建时间从 3 周降至 1 天
- 天猫店铺上线首月，「冷静蓝」在满屏暖色调的猫粮品类中点击率 4.3%，比品类平均 2.8% 高出 1.5 个百分点（用户反馈：「在一堆橘色黄色里，这个蓝色看起来很专业」）
- 后续所有小红书笔记、公众号推文、详情页的视觉和语调严格一致——运营团队只需套用规范，不再逐页确认配色是否统一

> 🔑 **启示**：电商品牌的视觉规范不只是「好看的设计」——在高度同质化的品类（如宠物食品），它是货架上的「识别资产」。当 19/20 的竞品都用一个色系时，「不一样」本身就是最强的视觉钩子。而精确到 HEX 值的颜色规范，保证了店铺首页、详情页、推广图、直播间贴片在 20+ 个触点上的一致性。

## 7. 掌握检验

**Q1**：品牌系统的 5 个核心组成部分是什么？
- A) Logo、名片、信封、网站、广告
- B) 颜色调色板、字体系统、Logo 使用规则、图片风格、语调与文案规范
- C) 产品、定价、渠道、促销、包装
- D) 主色、辅助色、功能色、背景色、文字色

**Q2**：品牌一致性的三个层次中，最高层（Level 3）是什么？
- A) 视觉一致——颜色和字体正确
- B) 语调一致——文案风格统一
- C) 体验一致——用户感受和品牌承诺一致
- D) 格式一致——所有文件使用相同的模板

**Q3**：为什么品牌规范要用「精确数值」（如 #1E40AF）而非「模糊描述」（如「比较深的蓝色」）？如果使用模糊描述会出现什么具体问题？

**Q4**：「示例为王」原则——为什么每个品牌规则配「正确示例 + 错误示例」比写 10 页文字说明更有效？

**Q5**：你经营一个名为「茶颜山房」的高端茶叶品牌，请写出 3 条品牌文案语调规则，每条必须带正确示例和错误示例。规则应该覆盖用词风格、句式长度和情感基调。

**Q6**：brand-guidelines 的设计中，为什么规范文件放在 `references/` 中而非直接写在 `SKILL.md` 里？
- A) references/ 中的文件不能被 AI 读取
- B) SKILL.md 保持精简（原则 + 检查清单），详细规范按需加载，不占用每次对话的上下文
- C) SKILL.md 不支持颜色代码
- D) references/ 中的文件执行更快

**Q7**：品牌规范为什么被描述为「法律」而非「参考」？如果团队成员把品牌规范当作「参考」来使用，会导致什么后果？

## 8. 答案

**Q1**：**B** — Color Palette（颜色调色板）、Typography（字体系统）、Logo Usage（Logo 使用规则）、Imagery（图片风格）、Voice & Tone（语调与文案规范）。

**Q2**：**C** — Level 3 是体验一致（Experiential Consistency），用户不仅在视觉上认出品牌，而且在情感和体验层面上感受到一致。Level 1 是视觉一致（最低要求），Level 2 是语调一致。

**Q3**：参考答案 — 模糊描述（如「比较深的蓝色」）会导致每次 AI 输出的蓝色都略有不同——有的偏紫的蓝、有的偏绿的蓝、有的偏灰的蓝，最终品牌物料之间颜色不统一。精确数值确保在所有介质上、所有 AI 输出中、所有团队成员经手时，颜色都是一致的。品牌建设的本质是「重复产生记忆」——如果每次的颜色都不一样，就无法建立视觉记忆。

**Q4**：参考答案 — AI 不擅长理解抽象规则（「标题要有力量感」），但它极其擅长对比学习（「这个标题比那个标题更有力量感，因为有具体动词和数字」）。一对正确/错误的示例给 AI 一个边界——它知道了「过界」是什么样子。5 条规则 × 2 个例子 = 10 个案例，比 10 页文档效果好得多。

**Q5**：参考答案示例 — 规则 1（用词风格）：用东方、沉稳、有文化底蕴的词汇，避免网络流行语。✓ 「古树春芽·一盏入心」✗ 「这个茶绝绝子好喝」。规则 2（句式长度）：标题不超过 8 个字，正文每句不超过 25 字。✓ 「三百年古树，一叶一春秋」✗ 「我们这款茶是从具有三百年历史的古老茶树上面采摘下来的春茶芽头经过传统手工工艺精心制作而成的」。规则 3（情感基调）：传递「宁静、敬畏、珍惜」的感受。✓ 「限量 300 份，静待知音」✗ 「最后 3 天！再不买就没了！」

**Q6**：**B** — 这是渐进式披露的设计原则。SKILL.md 保持精简（原则 + 检查清单），详细规范放在 references/ 中按需加载。把所有规范都写在 SKILL.md 里会浪费每次对话的 token。

**Q7**：参考答案 — 品牌规范是「法律」意味着它是不容商量的约束。如果当作「参考」，团队成员会根据个人偏好自行调整——「我觉得这个蓝色更好看，稍微改一点应该没关系」——一个人改一点点、两个人改一点点，最终品牌的视觉碎片化，丧失了「一致性」这个品牌最核心的资产。
