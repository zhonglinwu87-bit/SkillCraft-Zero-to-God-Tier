# L5-15：PPT幻灯片生成 —— 精美演示文稿一句话搞定

> 🎯 **学什么**：不打开 PowerPoint，用一句话描述让 AI 生成一整份专业的演示文稿——有配色方案、有布局设计、有数据图表、有视觉元素。不是白底黑字的"学生作业"，而是真正能打动投资人和客户的商业级幻灯片。核心洞察：(1) "不做无聊的幻灯片"不是口号而是技术标准——检验方法：把封面页截图在手机缩略图大小看一眼，如果和任何其他白底黑字 PPT 没区别，就是无聊的；(2) 标题下的强调线是"AI 生成的标志"——几乎所有 AI 都默认在标题下加一条线，去掉它换留白，你的 PPT 立刻不像是机器做的；(3) 视觉 QA 必须用子代理——因为你自己已经盯着 PPT 做了半小时，大脑会自动修复你看到的瑕疵（知觉修复效应）。
> 💡 **难易度**：⭐⭐⭐⭐ | ⏱️ **预计时间**：50 分钟

***

## 1. 课程概览

> 💡 **白话小课堂**：你有没有经历过——明天要见投资人，今晚还在手动调 PPT？一页一页地排版、选配色、加图片、对齐文本框……做到凌晨三点还在改第三页的字体。document-pptx 解决的就是这个问题——用自然语言描述你要表达的内容，AI 生成一套完整的商业级幻灯片。

## 2. 两种创建模式

### 2.1 模式选择

```
Mode 1：从模板编辑（Template-Based）
  → 解包已有 .pptx → 操控 XML → 填入内容 → 打包
  → 解包工具：python scripts/office/unpack.py
  → 适合：有公司模板、必须保持品牌一致性
  → 场景举例：银行员工做季度汇报——公司有强制使用的模板（Logo 位置、
    页脚格式、配色方案固定）

Mode 2：从零创建（From Scratch）
  → 使用 pptxgenjs（JavaScript 库）
  → 完全自由设计——配色、字体、布局全部由 AI 创意
  → 适合：无模板约束、创业者做融资 PPT、电商卖家做品线汇报
  → 场景举例：创业团队做种子轮路演——没有品牌规范，需要从白纸开始

读取内容：
  python -m markitdown presentation.pptx     → 提取文本
  python scripts/thumbnail.py presentation.pptx → 生成缩略图预览
```

### 2.2 8 页最小可行 PPT

```
8 页是"最小可行 PPT"的黄金结构——刚好能把一个产品讲清楚，
也不至于太长。从 8 页开始练，熟练后再做 20 页。

Page 1：封面（Cover）
  → 一句话价值主张 + 品牌色/图 + 标题
  → 目标：观众 3 秒内知道"这是什么 + 谁在做"

Page 2：问题（Problem）
  → 目标用户当前面临的核心痛点
  → 目标：让观众说"这确实是个问题"

Page 3：解决方案（Solution）
  → 你的产品/服务如何解决 Page 2 的问题
  → 目标：让观众说"这个方案 make sense"

Page 4-6：三个核心卖点（3 Key Differentiators）
  → 每页只讲一个卖点——视觉先于文字
  → 目标：让观众记住 3 个为什么选你的理由

Page 7：数据证明（Proof / Traction）
  → 收入增长曲线、用户数、复购率、客户证言
  → 目标：让观众相信"这不是纸上谈兵"

Page 8：行动号召 + 封底（CTA + Thank You）
  → 明确下一步："联系我们""扫码试用""预约演示"
  → 目标：让观众知道"下一步做什么"
```

## 3. 配色方案的设计哲学

### 3.1 主导色优先原则

```
配色方案的核心原则：主导色优先

❌ 错误做法：五种颜色平分权重——观众不知道该看哪
✅ 正确做法：
  → 一个颜色占 60-70% 视觉权重（主导色——建立页面的视觉情绪）
  → 1-2 个辅助色调做支撑（辅助色——区分信息层次）
  → 1 个锋利的强调色做点缀（强调色——引导注意力到关键元素）

配色选择是"场景匹配"不是"好看选择"：

| 配色方案 | 适合场景 | 主导色情绪 |
|---------|---------|-----------|
| 午夜商务 | B2B、金融、企业 | 深蓝——专业、稳重 |
| 森林苔藓 | 环保、健康、有机品牌 | 绿色——自然、可持续 |
| 珊瑚能量 | 年轻、潮流、C端 | 珊瑚红——活力、冲动 |
| 温暖陶土 | 手作、自然、生活方式 | 大地色——温暖、真实 |
```

### 3.2 "无聊检测"

```
如何判断你的 PPT 是否无聊？

检测方法 1：缩略图测试
  → 把封面页截图
  → 在手机相册里缩略图大小看一眼
  → 如果它和任何其他白底黑字 PPT 没有区别 → 它是无聊的

检测方法 2：内容替换测试
  → 把内容从不相关的主题（"奶茶店商业计划"）换成另一个（"软件 SaaS 计划"）
  → 如果配色还能用 → 配色选择不够"内容驱动"
  → 好的配色应该和内容主题有内在关联
```

## 4. 常见错误的防御体系

### 4.1 九个常见错误

```
九条 PPT 设计中最高频的错误：

1. 标题下加线
   → 几乎所有 AI 生成的 PPT 都默认在标题下加一条绿色或蓝色的线
   → 这条线已成为"机器流水线产品"的视觉标签
   → 修复：把线换成留白——标题和内容之间的距离自然分隔

2. 每页塞满文字
   → 文档型 PPT 的标志——观众在读，不在听
   → 演讲型 PPT：每页一个核心信息，视觉先于文字

3. 忽视字号对比
   → 36pt 标题 + 14pt 正文——在会议室后排 14pt 看起来很吃力
   → 正文最小 18pt，标题最小 28pt

4. 只美化一页
   → 封面花了 30 分钟，其他页随便——视觉不一致比全程平庸更差
   → 观众会觉得"这个团队不认真"

5. 混合间距
   → 0.3 英寸和 0.5 英寸的段落间距混用——人眼对间距高度敏感
   → 统一一个间距值，全文使用

6. 居中正文
   → 段落列表应该左对齐（符合阅读习惯）
   → 标题可以居中，正文不要

7. 低对比文字
   → 浅灰色文字在白色背景上——投影仪下完全看不见

8. 无视觉层次
   → 观众不知道该先看哪——用大小、颜色、位置建立视觉层次

9. 数据图表无结论
   → 放一张图表但不说"这说明了什么"
   → 图表标题应该是结论——"Q4 收入首破 1000 万"而不是"季度收入"
```

## 5. 视觉 QA：子代理的必要性

### 5.1 为什么自己检查不了自己的设计

```
"知觉修复"（Perceptual Completion）现象：

你已经盯着这套 PPT 做了半小时 → 你的大脑对设计细节"脱敏"
  → 一个文字偏了 3 像素 → 大脑说"没关系，客户不会注意"
  → 标题与左侧边距差 0.2 英寸 → 大脑说"看起来差不多"
  → 两页的配色有微妙差异 → 大脑说"这是设计变化，不是错误"

子代理（Subagent）没有这种心理负担：
  → 它看到的就是白纸黑字
  → 它不会自动"修复"瑕疵
  → 它会直接报告"第 3 页标题偏右 3px，第 5 页配色与其余页不一致"

这就是为什么视觉 QA 必须用子代理而非自己检查：
  → 不是你不认真——是你生理上做不到
  → 子代理 = 一个没有"设计疲劳"的新鲜眼睛
```

## 6. 结构拆解：PPT 生成 Skill 模板

```markdown
## PPT 生成型 Skill 模板

### 核心特征
→ 管理对象 = PowerPoint 演示文稿（.pptx）
→ 核心原则 = 不做无聊的幻灯片 + 主导色优先 + 子代理 QA
→ 关键设计 = 两种创建模式 + 9 条错误防御 + 8 页最小结构

### 通用结构

## Two Creation Modes（两种创建模式）
- Mode 1: 模板编辑（解包 → XML → 打包）
- Mode 2: 从零创建（pptxgenjs）
- 读取：markitdown + thumbnail.py

## Design Principles（设计原则）
- 主导色优先：60-70% 主色 + 1-2 辅助色 + 1 强调色
- 无聊检测：缩略图测试 + 内容替换测试
- 8 页最小结构：封面→问题→方案→3卖点→数据→CTA

## Nine Common Mistakes（九个常见错误）
1. 标题加线 2. 塞满文字 3. 字号对比 4. 只美化一页
5. 混合间距 6. 居中正文 7. 低对比 8. 无层次 9. 图表无结论

## Visual QA（视觉质量检查）
- 子代理执行（绕过知觉修复）
- 检查项：对齐、间距、配色一致性、字号对比、可读性
```

## 7. 电商案例：月度运营复盘 PPT 自动生成

某天猫代运营团队（服务 5 个品牌方，每月需要向每个品牌方提交一份月度运营复盘 PPT）每份 PPT 约 12 页，结构固定：GMV 达成→各品类表现→推广 ROI→竞品动态→下月目标与策略。过去运营专员手动做 PPT：从天猫生意参谋导出截图→粘贴到 PPT→逐页输入数据→调格式。一份 PPT 耗 4 小时，5 个品牌方共 20 小时/月。

用 document-pptx 建立「数据驱动自动填充模板」。

**设计方案**：
- 模式：Mode 2（从零创建——pptxgenjs）
- 配色：每个品牌方使用各自品牌主色 + 深灰辅助（统一专业感 + 品牌辨识度）
- 结构：12 页运营复盘标准结构

**12 页数据驱动模板**：

```
Page 1：封面
  → 自动填入：「{品牌名} 天猫旗舰店 · 2026 年 4 月运营复盘」
  → 品牌主色渐变背景 + 品牌 Logo 左上角

Page 2：GMV 达成总览
  → 自动从数据源读取：月度 GMV、达成率、同比增长
  → 模板生成：大字「¥84.3 万」+ 达成率进度条（98.7%）+ 同比箭头「↑ 23% vs 去年同月」

Page 3-5：三大品类拆解（护肤品/彩妆/个护各一页）
  → 自动填入：品类 GMV、占比、增速、TOP3 SKU
  → 模板生成：柱状图（品类 GMV）+ 饼图（品类占比）

Page 6：推广 ROI
  → 自动填入：直通车消耗、引力魔方消耗、万相台消耗、整体 ROI
  → 模板生成：ROI 趋势折线图（4 周变化）

Page 7：流量来源分析
  → 自动填入：搜索/推荐/直播/短视频/购物车各渠道访客数和转化率
  → 模板生成：桑基图（流量来源 → 加购 → 成交）

Page 8：竞品动态
  → 手动选区（竞品洞悉数据来自人工观察，暂不可自动化）

Page 9：库存与退货
  → 自动填入：退货率、TOP 退货 SKU、库存深度

Page 10-11：下月目标与策略（手动填写区域为主）

Page 12：行动事项清单 + Thank You
```

**数据源结构**（运营每月只需更新一个 Excel 数据文件）：
```
品牌名 | 字段 | 4月 | 3月 | 去年同期 | 备注
零点零食 | GMV | 843000 | 762000 | 685000 |
零点零食 | 推广ROI | 3.2 | 2.8 | 2.1 |
...
```

**效果**：
- 月度复盘 PPT 制作时间：从 20 小时/月（5 品牌 × 4 小时）→ 2 小时/月（更新 Excel 20 分钟 + AI 生成 5 份 × 15 分钟 + 人工补充竞品/策略页 25 分钟）
- 数据错误率从「每份 PPT 总有 1-2 处数字抄错被品牌方指出」→ 零错误（数据源单一，不经过人手转录）
- 品牌方反馈：「这个月的 PPT 比之前专业了很多——格式统一，图表上都有结论标签」

> 🔑 **启示**：运营复盘 PPT 不是艺术品——它是格式固定、数据驱动的重复劳动。PPT 生成不是让 AI「设计一套全新的 PPT」，而是让 AI 把运营专员从「逐页复制粘贴数字」中解放出来。专员的时间应该花在竞品分析和策略建议上（PPT 的 20% 需要人脑的部分），而不是把 Excel 数据逐格敲进 PPT。

## 8. 掌握检验

**Q1**：PPT 配色方案中"主导色优先"原则指的是什么？
- A) 使用尽可能多的颜色来丰富视觉
- B) 一个颜色占 60-70% 视觉权重，1-2 个辅助色调 + 1 个强调色
- C) 全部使用同一颜色以保持简洁
- D) 每页使用不同的主色调以增加变化

**Q2**：为什么标题下的强调线被认为是"AI 生成的标志"？
- A) 因为只有 AI 能画出完美的直线

- C) 因为人类设计师不会使用线条
- D) 因为线条在 PowerPoint 中无法渲染

**Q3**：document-pptx 的两种创建模式（Mode 1: 模板编辑 vs Mode 2: 从零创建）分别适合什么场景？

**Q4**："不做无聊的幻灯片"的"无聊检测"方法是什么？

- A) 每页塞满文字，听众在读而不是在听
