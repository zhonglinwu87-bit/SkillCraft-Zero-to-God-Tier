# L2-07：引流磁铁设计 —— 匹配型 Skill 的「阶段 × 类型」路由设计

> 🎯 **学什么**：如何设计一个「先诊断、后匹配」的 Skill——根据用户画像和购买阶段，自动路由到最合适的引流策略。核心洞察：最差的引流磁铁是「全场 8 折」——它对任何阶段的人都没有特别的吸引力。引流磁铁的核心不是「给好处」，而是「给对的好处给对的人」。
> 💡 **难易度**：⭐ | ⏱️ **预计时间**：35 分钟

***

## 1. 课程概览

> 💡 **白话小课堂**：这个 Skill 就像一个商场门口的试吃摊设计师——它知道路过的人有的只是「闻闻味道」（认知阶段），有的在「货比三家」（考虑阶段），有的已经「打开钱包了」（决策阶段）。对第一种人，你该递一小块试吃品（自测工具、清单）——让人尝到甜头但不需要承诺什么。对第二种人，你该递一张详细的菜单介绍（对比指南、白皮书）。对第三种人，你直接说「第一个月半价」（免费试用）。最蠢的做法是对所有人都喊「全场 8 折」——还没认识你的人不在乎折扣，已经要买的人你不打折他也会买。

> **本课的独特定位**——匹配型 Skill 的路由设计：

| 做法 | 一刀切（一个磁铁所有人用） | 匹配型（本课） |
|------|---------------------|------------|
| 认知阶段用户 | 收到「免费试用」→ 太急了 | **自测工具**——「先了解自己有没有这个问题」 |
| 考虑阶段用户 | 收到「全场8折」→ 没有帮助 | **对比指南**——「帮你在多个方案中做选择」 |
| 决策阶段用户 | 收到「行业清单」→ 太浅了 | **免费试用 / Demo**——「让你零风险体验」 |

> 🔑 **核心秘诀**：匹配型 Skill 的正确流程是「先诊断阶段 → 再匹配策略 → 最后生成内容」——而不是用户说「我要引流」就随机推荐。这和 L1-10 的「先 Initial Assessment，后给建议」是同一个设计原则。

> ⚠️ **避坑指南**：「全场 8 折」是万能但无效的磁铁。对认知阶段：人家还不认识你，打不打折不关心。对考虑阶段：人家在货比三家，8 折不如一篇清晰的对比指南有价值。对决策阶段：已经要买了，你多此一举。

## 2. 买家阶段匹配矩阵详解

### 2.1 三个买家阶段

```
认知阶段（Awareness）：
  用户心理：「我有这个问题吗？」「这是什么东西？」
  用户行为：第一次搜到这个品类、第一次听说你的品牌
  需要的不是：「立即购买」——太急了
  需要的是：「让我知道我有这个问题」——先建立认知

考虑阶段（Consideration）：
  用户心理：「有哪些解决方案？」「A 和 B 有什么区别？」
  用户行为：在多个品牌之间比较、看评测、读对比文章
  需要的不是：「关注领券」——太浅了
  需要的是：「帮我判断哪个方案更适合我」——辅助决策

决策阶段（Decision）：
  用户心理：「我该选哪个？」「现在买还是等等？」
  用户行为：已经确定了品类，在最后几家之间犹豫
  需要的不是：「行业入门清单」——太基础了
  需要的是：「推我一把的理由」——消除最后疑虑
```

### 2.2 匹配矩阵

| 购买阶段 | 用户心理 | 最佳磁铁类型 | 典型示例 | 核心动作 |
|---------|---------|-------------|---------|---------|
| **认知** | 「我有这个问题吗？」 | 自测工具、清单、行业报告 | 「你的 SEO（SEO：搜索引擎优化） 健康度？免费检测」 | 让用户**发现自己**有需求 |
| **考虑** | 「有哪些解决方案？」 | 对比指南、白皮书、案例研究 | 「2026 营销工具终极对比」 | 帮用户**理解选择** |
| **决策** | 「我该选哪个？」 | 免费试用、Demo、优惠券 | 「7 天免费试用，无需信用卡」 | 给用户**最后一推** |

### 2.3 为什么错误匹配比不匹配更糟？

```
错误匹配示例 1：认知阶段 → 给「免费试用」
  用户：第一次听说你的 SEO 工具
  你：来，免费试用 7 天！
  用户心理：我连 SEO 是什么都不太清楚，你给我一个工具干嘛？
  结果：用户直接忽略，而且觉得「这个品牌不懂我」

错误匹配示例 2：决策阶段 → 给「入门清单」
  用户：已经在你和竞品之间比较了 3 天
  你：下载这份《SEO 入门 10 步清单》！
  用户心理：我是来买工具的，不是来上课的
  结果：用户觉得「你们到底想不想卖？」

错误匹配示例 3：考虑阶段 → 给「全场 8 折」
  用户：在比较你的 ¥399 方案和竞品的 ¥499 方案
  你：全场 8 折！
  用户心理：我需要知道为什么你的 ¥399 比竞品 ¥499 好，不是再便宜一点
  结果：价格不是他现在最关心的——价值才是
```

> 🔑 **核心洞察**：匹配型的核心不是「提供很多选择」，而是「只提供对的」——因为在错误的阶段给错误的磁铁，用户不是「不需要」，而是「觉得你不懂他」。

## 3. 磁铁类型详解 —— 8 种磁铁 + 各自设计要点

### 3.1 八种磁铁类型全景

| 类型 | 感知价值 | 用户投入 | 最佳阶段 | 设计要点 |
|------|:--:|:--:|:--:|------|
| **清单 (Checklist)** | 中 | 低 | 认知 | 5-10 项，具体可执行 |
| **速查表 (Cheat Sheet)** | 中 | 低 | 认知 | 一页纸，即查即用 |
| **模板 (Template)** | 高 | 低 | 认知/考虑 | 填空即用，省时间 |
| **自测工具 (Quiz/Assessment)** | 高 | 中 | 认知 | 个性化结果，制造好奇 |
| **对比指南 (Comparison Guide)** | 高 | 中 | 考虑 | 诚实对比，不吹不黑 |
| **白皮书/报告 (Whitepaper)** | 很高 | 中 | 考虑 | 数据驱动，有深度 |
| **免费试用 (Free Trial)** | 最高 | 中 | 决策 | 低门槛开始，无需信用卡 |
| **Demo/咨询 (Demo/Consultation)** | 最高 | 高 | 决策 | 个性化演示，针对性强 |

### 3.2 认知阶段磁铁的设计要点

```
清单 (Checklist) 的设计：
  ✅ 「独立开发者出海 SEO 10 步启动清单」
  → 具体：针对「独立开发者」而不是「所有人」
  → 可执行：10 步而不是「SEO 最佳实践大全」
  → 低投入：用户一看就知道 10 分钟能看完

自测工具 (Quiz) 的设计：
  ✅ 「3 分钟测出你的 SaaS（SaaS：软件即服务） 产品定价是否合理」
  → 个性化：你的定价 → 你的结果（不是通用理论）
  → 好奇心：用户想知道「我的定价是偏高还是偏低？」
  → 低门槛：3 分钟 vs 「完成 50 道题的全面评估」
```

### 3.3 考虑阶段磁铁的设计要点

```
对比指南 (Comparison Guide) 的设计：
  ✅ 「2026 独立开发者建站工具横评：Framer vs Webflow vs 自建」
  → 具体对象：三个工具，而不是「所有建站工具」
  → 诚实对比：每个工具的优缺点都写，不因为是你的竞品就贬低
  → 决策辅助：最终不强势推荐——「取决于你的需求」

白皮书 (Whitepaper) 的设计：
  ✅ 「独立开发者出海：2026 支付与定价趋势报告」
  → 数据驱动：有调查数据、有图表、有来源
  → 有洞察：不只是罗列数据——有分析和建议
```

### 3.4 决策阶段磁铁的设计要点

```
免费试用 (Free Trial) 的设计：
  ✅ 「7 天免费试用，无需信用卡」
  → 「无需信用卡」是降低门槛的关键——用户最怕「忘记取消被扣款」
  → 7 天足够体验核心功能（1 天太少，30 天太长）

Demo 的设计：
  ✅ 「15 分钟 1 对 1 产品演示，针对你的业务场景」
  → 针对性的比通用版的好
  → 15 分钟比 30 分钟更好约（30 分钟对决策者是很大的时间投入）
```

## 4. 内容封闭策略 —— 全封 vs 半封 vs 不封

### 4.1 三种策略的适用场景

```
全封闭（必须填邮箱才能获取）：
  适用：高感知价值的内容（白皮书、模板、工具）
  风险：如果内容不够好，用户会反感——「就这？还让我填邮箱？」
  原则：你换用户邮箱的东西，必须是用户愿意付费的内容

半封闭（预览部分，完整版需邮箱）：
  适用：对比指南、案例研究
  示例：博客文章版对比（公开）+ 完整 Excel 对比表（需邮箱）
  优势：用户先看到部分价值 → 更有动力填邮箱

无封闭（完全公开）：
  适用：清单、速查表、短内容
  理由：这些内容太短，不值得用户填邮箱——直接公开更有利于 SEO 和品牌
```

### 4.2 封闭策略的「价值匹配」原则

```
内容价值 > 邮箱价值 → 可以全封闭（用户觉得「值」）
内容价值 ≈ 邮箱价值 → 半封闭（让用户先看到部分价值）
内容价值 < 邮箱价值 → 不封闭（直接公开做 SEO）
```

> 🔑 **设计要点**：封闭策略不是「能封就封」——封一个不值邮箱的内容，用户不仅这次不给，以后也不会再信你的磁铁。这和 L1-10 弹窗的「价值必须明显」原则是一致的：你打断用户需要给补偿，你要用户邮箱需要给等价物。

## 5. 结构拆解：匹配型 Skill 模板

从 L2-07 提取「匹配型」Skill 的通用模板：

```markdown
## 匹配型 Skill 模板

### 核心特征
→ 核心流程 = 先诊断 → 后匹配 → 再生成
→ 核心挑战 = 准确判断用户所处的阶段/类型
→ 核心价值 = 不给用户「所有选项」，只给「对的选项」

### 通用结构

## Diagnostic Layer（诊断层）
- 判断维度：[用户阶段 / 用户类型 / 预算 / 目标...]
- 每个维度的判断标准
- 错误诊断的后果（错误匹配比不匹配更糟）

## Matching Matrix（匹配矩阵）
| 诊断结果 | 推荐策略 | 典型方案 | 为什么 |
| 阶段A → | 策略A → | 方案A → | 理由A |
| 阶段B → | 策略B → | 方案B → | 理由B |

## Strategy Details（策略详解）
每种策略的：
- 适用场景（什么时候用）
- 设计要点（怎么做才有效）
- 常见错误（为什么这样做没用）

## Gating Strategy（内容封闭）
- 全封闭：什么时候合适
- 半封闭：什么时候合适
- 不封闭：什么时候合适
- 原则：内容价值 ≥ 用户付出的「成本」（邮箱/时间）
```

**什么时候用匹配型？** → 当 Skill 需要根据用户特征路由到不同策略时：引流磁铁（买家阶段 × 磁铁类型）、弹窗策略（目标 × 触发方式）、邮件序列（用户阶段 × 邮件类型）——任何「不同的人需要不同的东西」的场景。

**匹配型与 L1-10 顾问型的关系**：

| | L1-10 AI 原生顾问型 | **L2-07 匹配型** |
|------|------|------|
| 流程 | Initial Assessment → 建议 | **诊断用户阶段 → 匹配策略矩阵** |
| 输出 | 策略建议列表 | **具体内容（生成的磁铁）** |
| 核心设计 | 三原则约束 | **阶段 × 类型矩阵** |

## 6. 电商案例：店铺拉新赠品策略设计

> 🛒 **实战案例**：某家居收纳品牌在淘宝上有三个主要价格带产品——¥29.9 的塑料收纳盒（引流款）、¥89 的布艺收纳柜（利润款）、¥269 的实木置物架（形象款）。店铺一直用「满 99 减 5」做拉新，但不同客单价区间的顾客对这个统一优惠的反应天差地别：买收纳盒的嫌「满 99 才减 5，我买 4 个也不够门槛」；买置物架的觉得「我花 269 你才减 5 块，当我是什么」。
>
> **用匹配型 Skill 设计分客单价赠品策略**：
>
> | 客单价区间 | 顾客心理 | 旧策略 | 新赠品方案 | 匹配逻辑 |
> |---------|---------|--------|-----------|---------|
> | ¥0-¥50 | 「我就想花小钱试一下」 | 满 99 减 5 | 「加购 1 元得 ¥9.9 防潮垫一包」 | 认知阶段：先让用户拿到实物体验 |
> | ¥50-¥150 | 「这个看起来不错，再看看」 | 满 99 减 5 | 「满 89 送同系列收纳盒 3 件套旅行装」 | 考虑阶段：赠品关联品引发连带购买 |
> | ¥150+ | 「我想买好的，但别让我觉得买亏了」 | 满 99 减 5 | 「满 199 送价值 ¥59 樟木防虫条 + 终身免费更换」 | 决策阶段：高感知赠品 + 长期承诺消除最后疑虑 |
>
> **赠品钩子的落地执行**：
> - ¥0-¥50 区间：在商品详情页第一屏加入「1 元换购防潮垫」入口，目的是拿到用户首次购买数据（即使不赚钱）
> - ¥50-¥150 区间：在购物车页面弹出「还差 ¥X 就能获得旅行装赠品」，X 根据当前购物车金额动态计算
> - ¥150+ 区间：在结算页面展示「终身免费更换」服务卡——每年可申请一次免费替换防虫条
>
> **效果**（换策略后 60 天数据）：
> - ¥0-¥50 区间转化率：2.8% → 5.9%（1 元换购降低首次购买决策门槛）
> - ¥50-¥150 区间客单价：¥73 → ¥96（用户凑单拿到赠品）
> - ¥150+ 区间转化率：1.9% → 3.5%（「终身更换」打消了实木产品「用一年就废」的顾虑）
> - 新客首单率（进店后 7 天内完成首单）：从 6.2% → 11.4%
>
> > 🔑 **启示**：好的赠品策略和差的赠品策略，差距不在赠品的成本，而在「匹配度」——花 3 块钱做的 1 元换购，比 5 块钱的满减券更能让 ¥29.9 用户迈出第一步。匹配型 Skill 的核心是让每个客单价区间的顾客，都收到一个「刚好解决他当前顾虑」的信号。

## 8. 答案

<details>
<summary>点击查看答案</summary>

**Q1**：**B** — 正确流程是「先诊断阶段 → 再匹配策略 → 最后生成内容」。错误流程是用户说「我要引流」就随机推荐——可能给出不搭的磁铁。匹配型 Skill 的核心是「先问再推」。

**Q2**：**B** — 认知阶段用户的心理是「我有这个问题吗？」，最佳磁铁是自测工具和清单（如「你的 SEO 健康度？免费检测」）。免费试用对应决策阶段（「我该选哪个？」），对比指南对应考虑阶段（「有哪些解决方案？」）。

**Q3**：**B** — 引流磁铁的核心不是「给好处」，而是「给对的好处给对的人」。新观众刚刷到视频还不认识品牌（认知阶段），你直接给券催下单 = 太急；老观众反复看但没下单（考虑阶段），他需要的是「为什么选你的面霜而不是别家」的信息，10 元券太浅。

**Q4**：**B** — 「全场 8 折」是万能但无效的磁铁。对认知阶段：人家还不认识你，打不打折不关心。对考虑阶段：人家在货比三家，8 折不如一篇清晰的对比指南有价值。对决策阶段：已经要买了，你多此一举。

**Q5**：认知阶段 → 「3 分钟测出你的课程学习风格」（自测工具，因为用户还不知道自己需要这个课）；考虑阶段 → 「2026 在线课程平台横评：小鹅通 vs 知识星球 vs 自建站」（对比指南，因为用户在比较学什么和在哪学）；决策阶段 → 「免费试听前 3 节 + 不满意全额退」（免费试用/零风险承诺，因为用户就差最后一推）。认知阶段用户最大的问题是「我不知道我需要学这个」——自测工具让用户自己发现需求，而非被推销。

**Q6**：这个钩子用了两个心理机制：(1) 「承诺一致性」——用户打出「测评」两个字，等于公开承诺了「我感兴趣」，之后更有可能完成测评并关注；(2) 「好奇心缺口」——「你是什么等级」制造了一个认知缺口，用户想填补它。对比「关注领 10 元券」——用户不需要做任何认知投入，领完就忘。此外，评论区打「测评」会产生羊群效应，其他人看到很多评论会想「这么多人在测，我也试试」。

（5/6 通过）
