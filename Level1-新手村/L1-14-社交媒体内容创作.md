# L1-14：社交媒体内容生成 —— 一套框架管住所有平台

> 🎯 **学什么**：从「单一功能」到「策略框架」的范式升级——如何设计一套决策系统（内容支柱 + Hook 模板 + 复用工作流 + 平台适配规则），让 AI 不是「每次猜你要发什么」，而是「按你的策略体系稳定输出」。
> 💡 **难易度**：⭐⭐ | ⏱️ **预计时间**：50 分钟

***

## 1. 课程概览

> 💡 **白话小课堂**：前面十三课教的都是「单一功能」的 Skill——压缩图片、格式化排版、生成封面图——输入明确，输出明确。L1-14 教的是「策略框架」型 Skill：你给 AI 的不是「帮我写一篇 LinkedIn 帖子」，而是「这是我的内容策略——5 根支柱、4 种钩子（Hook）、5 个平台的适配规则——以后每次按这个体系给我出内容」。说白了，你把内容策略**编码进 Skill 里**，AI 就成了你的「策略执行器」——不是每次想发什么，而是体系在自动运转。

> **本课的独特定位**——这是 Level 1 中唯一「把策略编码进 Skill」的课程：

| 课程 | Skill 的本质 | AI 的角色 |
|------|------------|---------|
| L1-01~L1-12 | 功能封装（一个任务一个 Skill） | 工具执行者 |
| **L1-14（本课）** | **策略框架（一套决策系统管全部内容）** | **策略执行器** |

> 🔑 **核心秘诀**：social-content 不是「写帖子的 Skill」——它是「让 AI 理解你的内容策略，然后按策略自动产出」的框架。四个子系统协同工作：**内容支柱**告诉 AI 该写什么类型（行业洞察 30% / 幕后 25% / 教育 25% / 个人 15% / 推广 5%），**Hook 公式**保证每篇开头都达标（好奇心 / 故事 / 价值 / 反常识），**内容复用**把一篇长文拆成 5 个平台的适配版本（同源异形），**平台适配矩阵**确保同一观点在不同平台的语气和格式都正确。

> ⚠️ **避坑指南**：不要把内容复用等同于「复制粘贴」。同一篇博客发到 5 个平台不是「复制 5 次」，而是「提取核心素材 → 为每个平台重新表达」。LinkedIn 用户在工作模式下阅读（要深度），Twitter 用户在信息流中快速刷过（要锋利），小红书用户在「被安利」模式下浏览（要亲切）。同源异形——核心观点一致，表达方式各异。

## 2. 内容支柱框架详解 —— 让 AI 知道「该写什么」

这是 social-content Skill 的第一个核心设计——不是让 AI 每次都从零思考「发什么好」，而是给它一套**分类体系 + 比例分配**，让内容生产变成一个「按比例填充」的过程。

### 2.1 为什么需要内容支柱？

```
没有内容支柱（AI 自由发挥）：
  你：「帮我写一篇社交媒体帖子」
  AI：「好的，这是一篇产品介绍帖」
  你：「再写一篇」
  AI：「好的，这是一篇产品介绍帖」（又来了！）
  → 问题：AI 缺乏战略性判断——它不知道「你需要在不同角度之间轮换」

有内容支柱（AI 按策略执行）：
  你：「帮我写一篇社交媒体帖子」
  AI：检查历史记录 → 发现最近 4 篇中 2 篇是行业洞察、1 篇教育、1 篇个人
      → 「这周还没发幕后内容，给你写一篇团队内部故事」
  → 效果：内容自动轮换，不会在某一个角度上反复打转
```

> 🔑 **一句话总结**：内容支柱解决的是「AI 不知道该说什么」的问题——给它一个分类框架，它就知道在各种类型之间怎么分配注意力。

### 2.2 五根支柱模型

social-content Skill 内置了 5 根内容支柱（以 SaaS 创始人为例）：

| 支柱 | 占比 | 典型话题 | 为什么这个比例 |
|------|:--:|---------|--------------|
| **行业洞察** | 30% | 趋势分析、数据解读、预测 | 建立专业权威——别人关注你是为了获取行业判断力 |
| **幕后故事** | 25% | 创业过程、团队文化、失败教训 | 建立真实感和信任——人们追随的是人，不是 Logo |
| **教育内容** | 25% | 操作教程、思维框架、技巧分享 | 提供实用价值——「关注这个人有用」 |
| **个人观点** | 15% | 价值观表达、故事分享、热辣评论 | 建立情感连接——区分你和「内容机器」 |
| **产品推广** | 5% | 功能更新、优惠活动 | 转化——但不能超过 5%，否则用户取关 |

> 🔑 **设计要点**：比例不是随便写的——行业洞察 + 教育占了 55%，因为「专业可信 + 有用」是社交媒体关注的核心驱动力。幕后 + 个人占了 40%，用来建立「这是个真人而非品牌账号」的亲近感。推广只有 5%——多了取关，少了没法转化。这个 30/25/25/15/5 不是教条，是经验起点——你可以按自己的情况调整。

### 2.3 支柱开发问题——把策略变成可执行的清单

Skill 不只需要分类，还需要**帮用户定义每个支柱的具体内容**。social-content 的做法是内置 5 个开发问题：

```
对每根支柱，问用户（或引导用户自问）：
1. 独特视角——你在这个领域有什么别人没有的见解？
2. 受众疑问——你的受众经常问你什么？
3. 历史表现——以前什么内容效果最好？
4. 可持续性——什么内容你能长期稳定产出？
5. 商业关联——这根支柱怎么连接到你的业务目标？
```

> 🔑 **设计要点**：这 5 个问题不是「随便问问」——它们把「内容策略」这个模糊概念变成了可以填空的清单。每个问题的输出直接变成 AI 生成内容时的约束条件。问题 4（可持续性）尤其重要——很多人规划内容时想得很好，但一个月后就没东西可写了。问「什么你能坚持写一年」，答案才是真正有用的支柱。

### 2.4 内容支柱作为 Skill 设计模式

这不是 social-content 独有的——任何需要「分类 + 比例 + 轮换」的生成型 Skill 都可以用这个模式：

```
通用模板：
1. 定义 N 个类别（支柱）
2. 给每个类别分配比例（%）——确保多样性
3. 为每个类别定义触发条件和话题池
4. 每次生成时，AI 先检查历史比例 → 选择比例不足的类别 → 从话题池中取话题
```

**可推广场景**：
- 邮件营销 Skill：促销 10% / 教育 40% / 故事 30% / 产品更新 20%
- 视频内容 Skill：教程 40% / Vlog 25% / 访谈 20% / 产品展示 15%
- 播客 Skill：深度访谈 50% / 单人独白 30% / 听众问答 20%

## 3. Hook 公式系统 —— 让 AI 的「第一句话」永远达标

### 3.1 为什么 Hook 必须用公式约束？

社交媒体的残酷现实：用户在信息流中的停留决策发生在**前 3 秒**。第一句话（Hook）决定了 90% 的阅读量。

```
AI 自由发挥写 Hook：
  「今天我分享一个关于产品营销的看法」 ← 平淡，没动力点开
  「我们最近发布了一个新功能」 ← 像新闻稿，不是社交媒体
  「以下是关于增长策略的一些思考」 ← 谁在乎？
  
  → 问题：AI 默认的「安全表达」恰恰是社交媒体最致命的——平淡、无钩子、无紧迫感。

AI 用 Hook 公式写 Hook（同样的主题）：
  Curiosity Gap：「我们试了 6 种增长策略——只有一种有效。猜猜是哪一种？」
  Contrarian：「大多数 SaaS 公司的增长策略是错的。我们砍掉了 80% 的渠道，反而增长了 3 倍。」
  Value：「如何在 30 天内让产品页面转化率翻倍（不需要重新设计）：」
```

> 🔑 **核心洞察**：Hook 公式不是「限制 AI 的创造力」，而是「给 AI 一个经过验证的注意力抓取结构」。AI 在公式框架内发挥，比完全自由发挥写出好 Hook 的概率高得多。

### 3.2 四种 Hook 公式详解

social-content Skill 内置了 4 种 Hook 模板，每种有独特的心理机制和适用场景：

#### 公式 1：好奇心缺口（Curiosity Gap）

**心理机制**：人脑对「未完成信息」有强烈的填补冲动——你开了一个缺口，读者必须点开才能闭合。

**模板**：
```
- "I was wrong about [common belief]."
- "The real reason [outcome] happens isn't what you think."
- "[Impressive result] — and it only took [surprisingly short time]."
- "I tried [thing] for [period]. The result surprised me."
```

**适用**：实验结果、个人体验、反直觉发现、数据对比

**为什么有效**：制造了一个「信息不对称」——你知道了读者还不知道的事，他们必须看下去才能填补这个缺口。

#### 公式 2：故事钩子（Story Hook）

**心理机制**：人类大脑对故事的响应是硬连线的——故事激活镜像神经元，让读者「代入」你的经历。

**模板**：
```
- "Last week, [unexpected thing] happened."
- "I almost [big mistake/failure]."
- "3 years ago, I [past state]. Today, [current state]."
```

**适用**：个人经历、转型故事、失败教训、成长记录

**为什么有效**：故事钩子不卖东西——它邀请读者进入一个已经开始的叙事，读者本能地想「然后呢？」

#### 公式 3：价值钩子（Value Hook）

**心理机制**：直接承诺效用——「点开这篇，你会得到 X」——简单粗暴但有效。

**模板**：
```
- "How to [desirable outcome] (without [common pain]):"
- "[Number] [things] that [outcome]:"
- "Stop [common mistake]. Do this instead:"
```

**适用**：教程、清单、对比、避坑指南

**为什么有效**：代价为零（看一眼），收益明确（学到一个东西），决策成本极低。

#### 公式 4：反常识钩子（Contrarian Hook）

**心理机制**：挑战既有认知——「你以为的可能是错的」——触发防御性好奇。

**模板**：
```
- "Unpopular opinion: [bold statement]"
- "[Common advice] is wrong. Here's why:"
- "I stopped [common practice] and [positive result]."
```

**适用**：行业观点、方法论挑战、经验分享

**为什么有效**：触发认知失调——读者必须看下去才能确认「我是对的还是他是对的」。

> 🔑 **设计要点**：四种公式覆盖了四个核心心理触发器——好奇心、故事代入、功利价值、认知挑战。如果一个 Hook 这四个都不触发，它大概率是无效的。

### 3.3 Hook 公式作为 Skill 设计原则

这是可以推广的 Skill 设计模式——「标准化底线」原则：

```
通用模式：
1. 识别任务中「质量差异最大的环节」（如社交媒体帖子的第一句话）
2. 为这个环节设计 N 个经过验证的模板（公式）
3. AI 的工作变为：判断内容适合哪个模板 → 在模板内发挥 → 输出
4. 模板保证下限（不会写出糟糕的结果），AI 的发挥决定上限

什么时候用：
- 任务中有「差一点就完全没用」的环节（标题、Hook、CTA、开场白）
- 完全自由发挥的不稳定性太高
- 可以归纳出经过验证的成功模式

什么时候不用：
- 任务需要高度个性化和灵活性
- 找不到可归纳的成功模式
- 模板限制大于帮助
```

> 🔑 **一句话**：Hook 公式设计 = 把「怎么写好第一句话」这个模糊要求，变成了「从 4 个模板中选最合适的，填进去」。

## 4. 内容复用系统 —— 「同源异形」的核心逻辑

### 4.1 什么是内容复用？不是什么？

```
内容复用 ≠ 复制粘贴
  错误做法：一篇博客 → 全文复制到 LinkedIn → 全文复制到 Twitter → 全文复制到小红书
  问题：每个平台的内容消费场景完全不同——LinkedIn 上的长篇博客在 Twitter 上根本没人看

内容复用 = 同源异形
  正确做法：一篇博客 → 提取核心素材（数据、金句、故事、观点）
           → LinkedIn：提取 3 个关键洞察 + 个人观点，写成专业文章
           → Twitter：拆成 5 条推文 Thread，每条一个独立洞察
           → Instagram：金句 + 视觉配图，做成信息卡片
           → TikTok：1 个核心 hook → 15-60 秒视频脚本
```

### 4.2 内容原子：复用的最小单位

social-content 的核心概念是「内容原子」（Content Atom）——从长篇内容中提取的自包含信息单元，每个原子可以独立存在并传递完整信息。

```
一篇博客文章包含的内容原子：
  ├── 核心观点（1-2 个）        → 可以变成 LinkedIn 帖子 + Twitter Thread
  ├── 数据/统计（3-5 个）       → 可以变成信息卡片 + Instagram 图文
  ├── 故事/案例（1-2 个）       → 可以变成视频脚本 + 个人分享帖
  ├── 操作步骤（2-4 个）        → 可以变成教程帖 + 清单卡片
  └── 金句/引用（2-3 个）       → 可以变成 Quote 图片 + 短视频字幕
```

**播客/视频的内容原子提取**：

| 原子类型 | 找什么 | 时长 | 适合平台 |
|---------|------|:--:|---------|
| 金句时刻 | 大胆声明、热评、难忘的句子 | 15-60s | Twitter/X, LinkedIn, TikTok |
| 故事弧线 | 完整迷你故事（设定→冲突→解决） | 60-90s | Reels, TikTok, Shorts |
| 战术技巧 | 具体的操作步骤或框架 | 30-60s | LinkedIn, Shorts |
| 争议观点 | 挑战主流的意见 | — | Twitter/X, LinkedIn |
| 数据亮点 | 令人惊讶的数字或研究发现 | — | LinkedIn 信息卡片, Twitter/X |
| 幕后花絮 | 真实、未剪辑的瞬间 | — | Instagram Stories, TikTok |

### 4.3 四套复用工作流

social-content Skill 内置了 4 套完整的内容复用转换表——本质上是「输入格式 → 输出格式」的映射规则：

**博客 → 社交媒体**：

| 平台 | 输出格式 |
|------|---------|
| LinkedIn | 关键洞察 + 个人观点（链接放评论区） |
| LinkedIn | 核心要点做成 Carousel（轮播卡片） |
| Twitter/X | 关键要点拆成 Thread |
| Instagram | Carousel 信息卡片 + 视觉配图 |
| Instagram | 把文章核心总结成 Reel |

**播客/视频 → 社交媒体**（6 步工作流）：
1. 获取文字稿（Whisper 或平台自带）
2. 标记时间戳——边听边标出 5-10 个最佳片段
3. 提取视频/音频片段
4. 为每个片段写独立配文（不假设观众看了其他部分）
5. 加字幕（大多数社媒视频静音播放）
6. 分散排期 1-2 周发布（不要一天全发）

**单集播客的目标产出**：
- 3-5 个短视频片段（15-60s）→ Reels/TikTok/Shorts
- 1-2 篇 LinkedIn 文字帖（关键洞察）
- 1 条 Twitter/X Thread（要点总结）
- 1 个 Carousel（框架或清单总结）
- 1 段 Newsletter/博客（精华段落）

**网络研讨会 → 社交媒体**：
- 关键幻灯片 + 点评 → LinkedIn Carousel
- Q&A 亮点 → Twitter/X Thread
- 嘉宾金句 → Instagram/LinkedIn 引用图
- 观众反应/投票结果 → 互动帖
- 完整录像 → 剪成短视频片段

**Newsletter → 社交媒体**：
- 核心洞察 → LinkedIn 帖子
- 精选链接 + 评论 → Twitter/X Thread
- 数据/统计 → 引用图
- 热辣观点 → Twitter/X 帖子 + LinkedIn

### 4.4 复用工作流作为通用 Skill 模式

```
"同源异形"模式的通用结构：

1. 创建支柱内容（长文/视频/播客/直播）
2. 提取内容原子（每篇 5-10 个自包含信息单元）
3. 按平台适配格式（每个平台有对应的输出规则）
4. 写独立配文（每个原子必须独立成立，不依赖上下文）
5. 分散排期（一周内均匀分布，不集中爆发）
6. 更新 + 再分享（长青内容每 3-6 个月可重复发布）

适用范围：任何「一份内容 → 多平台/多渠道分发」的场景
- 产品发布：产品介绍 → 短视频 demo / 图文评测 / 社群预告 / 邮件通知
- 品牌故事：一篇故事 → 短视频 / 图文 / 播客片段 / 新闻稿
- 研究报告：报告全文 → 信息图 / 数据卡片 / 短视频解读 / 媒体通稿
```

## 5. 短视频框架 —— 最高触达率的格式

### 5.1 3 秒规则

短视频是每个主流平台上触达率最高的格式。但你必须在前 3 秒内阻止滚动——每个视频需要**三个同时发生的钩子**：

```
[视觉钩子] + [口头钩子] + [文字叠加]
```

三个元素必须在第 1 秒同时出现。缺任何一个，你在损失一部分受众（有人静音、有人不看字幕、有人只瞥一眼）。

### 5.2 三种视频结构

**问题-解决方案（15-30s）**：
```
[0-3s]   钩子：直接说出问题
[3-10s]  搅动：为什么这问题值得关心
[10-25s] 解决方案：你的方法/产品/技巧
[25-30s] CTA：接下来做什么
```

**清单格式（30-60s）**：
```
[0-3s]   钩子：「X 个能让你 [结果] 的东西」
[3-50s]  逐条展示：每 5-8 秒一条
[50-60s] CTA
```

**教程格式（30-60s）**：
```
[0-3s]   钩子：先展示最终效果
[3-8s]   概览：「具体怎么做……」
[8-50s]  步骤：快速、清晰的指令
[50-60s] 结果展示 + CTA
```

### 5.3 字幕最佳实践

字幕能提升 25-40% 的观看时长。社交视频大多数是静音播放的：

- 屏幕上**最多 2 行**文字
- 每行 **3-5 个词**
- 粗体、无衬线字体 + 黑色描边
- **关键词高亮**（不同颜色）
- 时间轴精确对齐语音

## 6. 结构拆解：策略框架型 Skill 模板

从 L1-14 提取「策略框架型」Skill 的通用模板——这是前面所有架构之外的第七种模式。

```markdown
## 策略框架型 Skill 的四层设计

### Layer 1: 分类体系（内容支柱）
- 定义 N 个内容类别
- 每个类别分配比例（%）
- 每个类别开发话题池
- AI 每次生成时检查历史比例 → 选不足的类别

### Layer 2: 质量模板（Hook 公式）
- 识别质量方差最大的环节
- 设计 N 个经过验证的模板
- AI 选择模板 → 在模板内发挥
- 模板保下限，AI 冲上限

### Layer 3: 复用系统（内容原子）
- 定义内容原子的提取规则
- 建立「源格式 → 目标格式」映射表
- 每个原子独立成立（不依赖上下文）
- 分散排期，避免集中爆发

### Layer 4: 平台适配（格式矩阵）
- 每个平台的语气规则
- 每个平台的长度限制
- 每个平台的最佳内容类型
- AI 按矩阵自动适配
```

**策略框架型与前面六种架构的对比**：

| 特征 | 工具型 | 流水线型 | API桥接型 | AI生成型 | 参数化模板型 | 回溯式检查 | **策略框架型** |
|------|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| 核心设计 | 脚本封装 | 多步工位流 | 脚本+后处理 | 预览+迭代 | Preset+矩阵 | 单关注点+回溯 | **决策系统** |
| AI 角色 | 脚本调用者 | 排版师 | 数据获取者 | 创作者 | 模板选择器 | 审查者 | **策略执行器** |
| 用户输入 | 文件+参数 | 文章链接 | URL | 话题+偏好 | 话题+风格 | 现有文案 | **内容策略+话题** |
| 每次决策 | 0 | 1次 | 0-1次 | 2-3次 | 1次 | 0次 | **0次（策略已预编码）** |
| 输出 | 单文件 | 格式化文件 | 结构化数据 | 单文件+prompt | 多文件系列 | 修改建议 | **多平台内容组** |

**什么时候用策略框架型？** → 当 Skill 需要**持续产出**而非一次性生成时：
- 社交媒体内容运营（本课）
- 邮件营销序列（每周/每月自动生成邮件主题和内容）
- 内容日历规划（按策略自动排期和选题）
- 任何「系统 > 单次」的内容场景

**策略框架型的核心差异**：前面六种架构都是「一次调用完成一个任务」。策略框架型是「一次设定策略 → 持续按策略产出」——Skill 记住你的内容体系，每次自动在体系内运行。用户不需要每次说「写一篇行业洞察帖」，只需要说「写一篇帖子」，Skill 自己知道该写什么类型。

## 7. 电商案例：小红书商品种草笔记批量生成——5种达人风格×20个单品

> 🛒 **实战案例**：某护肤品牌有新系列「积雪草舒缓套装」（洁面+精华+面霜3件套），准备在小红书铺种草内容。品牌方自己只有1个账号，想让5种不同风格的达人（成分党、学生党、职场妈妈、敏感肌博主、护肤新手）各输出4篇笔记（20篇），覆盖"开箱→测评→对比→空瓶"四个阶段。如果一篇一篇手写，文案+配图+排版一篇要1.5小时，20篇就是30小时。
>
> **用 social-content Skill 做「同源异形」批量内容生产**：
>
> **Step 1：提取内容原子（从产品brief中）**
> - 核心成分数据：积雪草提取物含量85%、无酒精无香精、pH 5.5弱酸性
> - 核心卖点：修护屏障、退红、适合换季过敏——"3天退红"是消费者最直观感知的效果
> - 金句：「脸红了就是它在求救」「屏障不是墙，破了补不回来」
> - 使用场景：换季过敏急救、刷酸后修护、日常维稳
>
> **Step 2：按5种达人风格分配内容支柱**
> | 达人风格 | 4篇笔记角度 | 语言特点 |
> |---------|-----------|---------|
> | 成分党 | 积雪草文献考证→配方拆解→同类对比→浓度性价比 | 数据多、术语专业、"我查了文献" |
> | 学生党 | 平价替代大牌→宿舍护肤routine→军训晒后急救→月底空瓶记 | 口语化、省钱逻辑、"学生党冲" |
> | 职场妈妈 | 熬夜带娃急救→5分钟晨间护肤→宝宝也能用的安全成分→通勤包里的mini装 | 效率导向、安全优先、"没时间但不想丑" |
> | 敏感肌博主 | 换季翻车记录→7天退红实测→过敏期能用的只有它→和皮肤科医生聊成分 | 真实记录、对比图、"我的脸就是证据" |
> | 护肤新手 | 第一套护肤品怎么选→洁面精华面霜到底怎么用→"我以为过敏其实是缺水"→30天空瓶反馈 | 基础科普、避坑指南、"以前不懂现在懂了" |
>
> **Step 3：批量生成**
> - 每种风格设定语言基调（口语化/专业/温情）
> - Hook使用4种公式按阶段轮换：好奇心缺口（开箱篇）→价值钩子（测评篇）→反常识钩子（对比篇）→故事钩子（空瓶篇）
> - 20篇笔记+配图建议，统一品牌调性但各有人设
>
> **效果（发布后30天数据）**：
> - 20篇笔记总曝光：380,000+（品牌自有账号同期发4篇仅28,000曝光）
> - 合集笔记为品牌号引流涨粉5,400
> - "积雪草舒缓套装"搜索量从日均12次 → 日均340次
> - 品牌天猫店该系列30天销售额¥186,000（较上月同类新品增长410%）
>
> > 🔑 **启示**：小红书的种草不是"一篇爆文"的逻辑，而是"多个声音说同一件事"的网状覆盖。同一个人发4篇是刷屏——5种人设各发4篇是"大家都在用"。AI的价值不是替你想创意，而是让"一套产品素材→5种人设×4个阶段=20篇不同笔记"从不可能变成可能。不是复制粘贴，是「同源异形」。

## 8. 掌握检验

**Q1**：social-content Skill 的内容支柱框架包含哪五根支柱？各自的比例是多少？这个比例的设计逻辑是什么？

**Q2**：为什么内容支柱框架比「每次都让 AI 自由决定写什么」更好？这解决了 AI 内容生成的什么固有问题？

**Q3**：social-content Skill 提供了四种 Hook 公式。请列出每种公式的名称、心理机制、和典型模板（中英文均可）。

**Q4**：为什么用 Hook 公式模板比让 AI 即兴发挥写 Hook 更好？这体现了 Skill 设计的什么原则？这个原则可以推广到什么场景？

## 9. 答案

**Q1**：五根支柱及比例：1) **行业洞察（30%）**——趋势分析、数据解读、预测，建立专业权威；2) **幕后故事（25%）**——创业过程、团队文化、失败教训，建立真实感和信任；3) **教育内容（25%）**——操作教程、思维框架、技巧分享，提供实用价值；4) **个人观点（15%）**——价值观表达、故事分享、热辣评论，建立情感连接；5) **产品推广（5%）**——功能更新、优惠活动，实现转化。设计逻辑：55%（洞察+教育）建立「关注这个人有用」的专业价值，40%（幕后+个人）建立「这是个真人」的亲近感，5%（推广）保证商业转化但不至于取关。

**Q2**：内容支柱解决了 AI 内容生成的「策略盲区」——AI 不知道你的内容战略，它只会根据 prompt 给出看似合理的内容。没有支柱框架时，AI 可能在同一个角度反复输出（每次都是产品介绍），缺乏内容多样性和策略高度。支柱框架给 AI 一套**分类 + 比例 + 轮换机制**：分类让 AI 知道有哪些内容类型可用；比例让 AI 知道各类型该占多少；轮换机制让 AI 每次检查历史产出，自动选择比例不足的类型。本质上是把内容策略编码进了 Skill 的决策系统。

**Q3**：四种 Hook 公式：
1) **好奇心缺口（Curiosity Gap）**——心理机制：人脑对未完成信息有填补冲动。模板："I was wrong about [common belief]." "我试了 [某事] 30 天，结果让我震惊。"
2) **故事钩子（Story Hook）**——心理机制：故事激活镜像神经元，读者本能代入。模板："Last week, [unexpected thing] happened." "3 年前我 [过去状态]，今天 [现在状态]。"
3) **价值钩子（Value Hook）**——心理机制：直接承诺效用，决策成本极低。模板："How to [desired outcome] (without [pain]):" "别再 [常见错误] 了，试试这个方法："
4) **反常识钩子（Contrarian Hook）**——心理机制：挑战既有认知，触发防御性好奇。模板："Unpopular opinion: [bold statement]""[常见做法] 是错的，原因如下："

**Q4**：Hook 公式比 AI 自由发挥更好，因为社交媒体 Hook 是「差一点就完全没用」的关键环节——平淡的开头 = 没人点开 = 内容再好也没用。AI 自由发挥的不稳定性太高——有时写出好 Hook，有时写出「今天我们分享一个关于……」这种致命的平淡开头。Hook 公式体现的是 Skill 设计的**「标准化底线」原则**：为质量方差最大的环节设计经过验证的模板，模板保证下限（不会写出无效的 Hook），AI 在模板内的发挥决定上限（写出特别出彩的 Hook）。可推广场景：任何有「差一点就没用」环节的生成任务——邮件主题行、广告标题、视频开头、落地页 Headline、PPT 封面标题。

**Q5**：核心区别——复制粘贴是同一内容不经修改发到多个平台（「同源同形」），破坏了每个平台的内容消费场景适配。「同源异形」是提取核心素材（数据、金句、故事、观点），然后为每个平台重新表达——核心观点一致（同源），但长度、语气、格式按平台特性调整（异形）。「同源」= 核心观点、关键数据、品牌声音保持一致；「异形」= 每个平台的表达方式适配其受众习惯和阅读场景。本质上，复用是「理解内容基因 → 为每个平台长出合适的形态」，不是「把同一张脸贴到不同身体上」。

**Q6**：「内容原子」是从长篇内容中提取的自包含信息单元——每个原子包含完整信息，可以独立存在而不依赖上下文。类型：1) 核心观点（1-2 个）→ LinkedIn 帖子 + Twitter Thread；2) 数据/统计（3-5 个）→ 信息卡片 + Instagram 图文；3) 故事/案例（1-2 个）→ 视频脚本 + 个人分享帖；4) 操作步骤（2-4 个）→ 教程帖 + 清单卡片；5) 金句/引用（2-3 个）→ Quote 图片 + 短视频字幕。分配逻辑：每类原子有最适合的平台格式——数据类适合视觉型平台（Instagram 卡片），观点类适合文字型平台（LinkedIn/Twitter），故事类适合视频型平台（TikTok/Reels）。

**Q7**：三层分析——**内容支柱层**：行业洞察（传统手工艺商业化）→ LinkedIn 深度文章；幕后故事（匠人的一天）→ 抖音/TikTok 短视频；教育内容（银饰工艺科普）→ 小红书图文教程；个人观点（为什么选择手工艺电商）→ Twitter/X Thread；产品推广（本周作品上新）→ Instagram。**内容原子层**：从 3000 字故事中提取了 4 类原子——核心数据（50 年/3 代人/32 道工序）、金句（「机器做的银饰千篇一律……」）、匠人故事（15 岁学徒到 65 岁仍在打银）、商业洞察（传统手工艺的商业化困境）。**平台适配层**：公众号用长文阅读场景（精修 + 排版）；小红书用亲切口语 + 视觉教程；抖音用 Curiosity Gap Hook + 视觉钩子（匠人手部特写）；LinkedIn 用专业深度 + 数据引用；Twitter/X 用碎片化故事 Thread。效果：两周销售额 ¥87,000（此前月均 ¥12,000），增长 625%——核心驱动力是「哪里都能看到这个品牌」的多平台认知效应。

**Q8**：核心区别——前面六种架构都是一次调用完成一个任务：用户每次都需要提供输入、做出决策、等待输出。策略框架型是一次设定策略（内容支柱 + Hook 模板 + 平台规则）→ 之后持续按策略自动产出——用户只需要说「写一篇帖子」，Skill 自己知道该写什么类型、用什么 Hook、适配哪个平台。AI 的角色从「工具执行者」（我帮你做这件事）变成了「策略执行器」（我按你的策略体系自动运转）。这是 Skill 设计复杂度的最高形态——不是封装一个功能，而是封装一套决策系统。

（7/8 通过）
