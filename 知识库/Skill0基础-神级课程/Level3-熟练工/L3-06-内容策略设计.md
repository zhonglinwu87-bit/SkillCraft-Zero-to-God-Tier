# L3-06：内容策略规划 —— 二分法 + 支柱集群 + 优先级评分

> 🎯 **学什么**：学会用一个极其简单的二分法（可搜索 vs 可分享）规划全年度内容日历，用内容支柱+主题集群模型构建 SEO（SEO：搜索引擎优化）内容体系，用四维度加权评分决定先做什么内容。核心洞察：二分法的力量不在于"精确"，而在于"够用"——任何内容决策都变成"向左走（SEO）还是向右走（社媒）"，没有第三种可能，不纠结。
> 💡 **难易度**：⭐ | ⏱️ **预计时间**：40 分钟

***

## 1. 课程概览

> 💡 **白话小课堂**：这个 Skill 就像一个**总编辑+发行总监的合体大脑**——你有一个文章点子，AI 先问你"这篇文章是想让人搜到的还是想让人转发的？"如果是搜到的（可搜索内容），就帮你写 SEO 友好标题、做结构化教程、埋长尾关键词、建内链到 Pillar Page；如果是转发的（可分享内容），就帮你找独特观点、写争议标题、规划发到哪个社交平台。所有决策被一个极其简单的二分法统领。

> **本课的独特定位**——战略型 Skill（与"执行型"Skill 配合）：

| 类型 | 执行型 Skill（L3-05 文案） | 战略型 Skill（本课） |
|------|-------------------------|-------------------|
| 问题 | "怎么写？" | **"写什么？为什么写？先写哪个？"** |
| 输出 | 一篇文案 | **全年内容日历 + 优先级列表** |
| 时间跨度 | 当前这一刻 | **未来 3-12 个月** |
| 依赖 | L2-15 product-marketing-context | L2-15 + 关键词数据 |

> 🔑 **核心秘诀**：电商内容不是越多越好，是"搜得到的够专业、转得动的够有料"。搜索型内容是你的固定资产（一直在那产生价值），分享型是你的营销活动（短期爆发）。正确的策略是先建搜索资产"保底"，再用分享内容"冲高"——比例约 6:4 或 7:3。

> ⚠️ **避坑指南**：很多内容创作者把所有内容都当"可搜索"来做（标题全是关键词堆砌，毫无分享欲），或者把所有内容当"可分享"来做（每篇都追求爆款，没人搜得到）。结果：SEO 文章没人转发、社交文章搜索不到——双输。

## 2. 核心二分法：可搜索 vs 可分享

### 2.1 二分法的完整定义

```
可搜索内容（Searchable）— 捕获已有需求：
  前提：人们已经在搜索这个话题
  渠道：搜索引擎（Google/百度/小红书搜索）
  流量模式：持续稳定（只要排上去就一直有流量）
  内容特征：
    - "how to" 指南、教程
    - 对比评测（A vs B）
    - 工具型内容（计算器、模板、清单）
    - 长尾关键词覆盖
  优势：像固定资产——今天写的文章，3 年后还有流量
  劣势：起量慢——SEO 需要 3-6 个月才能见效

可分享内容（Shareable）— 创造新需求：
  前提：人们还不一定在搜这个话题
  渠道：社交平台（微信/微博/小红书/抖音/Twitter）
  流量模式：爆发式（一篇爆款可能带来 10 万+ 访问，但几天后沉寂）
  内容特征：
    - 争议观点、反常识结论
    - 独家数据、行业报告
    - 情感故事、个人经历
    - 实用清单（"10 个你必须知道的 XX"）
  优势：像营销活动——爆发力强，一篇爆款顶 50 篇 SEO（SEO：搜索引擎优化）文章
  劣势：不可预测——花同样时间写的分享内容可能爆可能沉
```

### 2.2 为什么是二分法而不是多分类法？

```
二分法（可搜索 vs 可分享）vs 多分类法（教程/对比/情感/数据/新闻/案例/...共 7-10 种）

二分法的优势：

对人：
  → 任何新选题一秒判断："这篇是让人搜的，还是让人转的？"
  → 没有第三种可能 → 不纠结
  → 决策效率：秒级 vs 分钟级

对 AI：
  → 拿到任何话题后一秒判断分类
  → 后续策略（标题写法/发布渠道/内容形式）自动匹配
  → 不会在"分类阶段"消耗大量判断力

多分类法的问题：
  → 边界模糊——"情感故事"和"个人经历"有什么本质区别？
  → AI 容易分类错误——分错了 = 后续策略全错
  → 用户需要学习分类体系——增加认知负担

核心洞察：够用就好。就像交通灯只有红黄绿——多一种颜色大家都得停下来想。
```

### 2.3 内容日历的黄金比例

```
推荐比例：搜索型 : 分享型 = 6:4 或 7:3

为什么搜索型占多数？
  → 搜索型内容 = 资产——一直在那产生价值
  → 就算分享型内容全部不爆，搜索型内容保底
  → 搜索型内容之间通过内链互相增强（网络效应）
  → SEO 需要内容积累，越写越多 = 权重越来越高

为什么分享型不能是 0？
  → 纯搜索型策略 = 流量天花板 = 搜索量上限
  → 分享型是唯一的"出圈"方式——触达不搜你的新人
  → 分享型内容的社交信号（转发/收藏/点赞）间接帮助 SEO
  → 爆款可以快速建立品牌认知

错误策略：
  9:1（几乎全搜索）→ 流量稳定但增长缓慢，不破圈
  1:9（几乎全分享）→ 粉丝数看上去多但流量大起大落，不可持续
  5:5 → 看似平衡但两者都不够深入
```

## 3. 内容支柱与主题集群模型

### 3.1 Hub-and-Spoke（轮毂-辐条 内容结构） 结构

这是 SEO（SEO：搜索引擎优化）内容体系的核心架构——像一个自行车轮子：

```
Pillar Page（支柱页）—— 轮毂
  → 覆盖一个主题的完整指南
  → 3000-8000 字的深度内容
  → 链接到所有相关的 Cluster 文章
  → 例如：《2026 年养猫完全指南》

Cluster Content（集群内容）—— 辐条
  → 围绕支柱的子主题文章
  → 800-2000 字的专项内容
  → 通过内链连接回 Pillar Page
  → 例如：
    - "7 款猫砂实测对比"
    - "布偶猫的 6 个常见健康问题"
    - "猫一天喝多少水才正常？兽医来告诉你"
    - "2026 年性价比最高的 10 款猫粮横评"

为什么要这样做？
  → Google 看到：一个 Pillar Page 被 4+ 篇 Cluster 文章链接
  → Google 判断：这个页面是这个主题的"权威中心"
  → Pillar Page 排名提升 → 所有 Cluster 文章的排名也提升
  → 网络效应：1+1+1+1+1 > 5（互相增强）
```

### 3.2 电商内容支柱体系示例

```
宠物用品电商的 3 大支柱体系：

Pillar 1: 《2026 年养猫完全指南》
  Cluster 1-1: 猫砂对比（膨润土 vs 豆腐 vs 松木）
  Cluster 1-2: 布偶猫健康问题与预防
  Cluster 1-3: 猫咪每天喝多少水才正常
  Cluster 1-4: 性价比猫粮横评

Pillar 2: 《新手养狗从 0 到 1》
  Cluster 2-1: 适合公寓养的 10 种小型犬
  Cluster 2-2: 狗狗疫苗全攻略（时间表+费用）
  Cluster 2-3: 分离焦虑怎么办？训犬师的方法

Pillar 3: 《宠物出行全攻略》
  Cluster 3-1: 带猫坐飞机的完整流程
  Cluster 3-2: 2026 年宠物友好酒店清单
  Cluster 3-3: 车载宠物安全装备测评
```

## 4. 优先级评分系统

### 4.1 四维度加权评分

有了选题池（Pillar + Cluster + 分享型点子），怎么决定先做哪个？

```
Priority Score = 
  客户影响 (40%) + 内容市场匹配 (30%) + 搜索潜力 (20%) + 资源需求 (10%)

维度详解：

1. 客户影响（Customer Impact）— 权重 40%
   → 这个内容解决客户多大的问题？
   → 评分：1-5 分
   → 5 分 = 解决核心痛点，不解决就不买
   → 1 分 = 锦上添花，可有可无

2. 内容市场匹配（Content-Market Fit）— 权重 30%
   → 竞品有没有覆盖这个话题？
   → 评分：1-5 分
   → 5 分 = 竞品几乎没有覆盖，蓝海
   → 1 分 = 竞品已有 10+ 篇高质量内容

3. 搜索潜力（Search Potential）— 权重 20%
   → 这个话题的月搜索量 × 转化潜力
   → 评分：1-5 分
   → 5 分 = 月搜索量 >5000 + 高购买意图
   → 1 分 = 月搜索量 <100 或 纯信息查询（无购买意图）

4. 资源需求（Resource Requirement）— 权重 10%
   → 做这个内容需要多少投入？
   → 评分：1-5 分（越低越好，投入少 = 分高）
   → 5 分 = 2 小时内能完成
   → 1 分 = 需要 1 周以上的原创数据/测试/采访

示例计算：
  选题"布偶猫常见健康问题"：
    客户影响 = 5（养布偶猫的核心焦虑点）
    市场匹配 = 3（已有一些竞品文章，但不深入）
    搜索潜力 = 4（"布偶猫 生病"月搜 2800+）
    资源需求 = 4（兽医博客可翻译+改编，4 小时完成）
  总分 = 5×0.4 + 3×0.3 + 4×0.2 + 4×0.1 = 2.0+0.9+0.8+0.4 = 4.1/5.0
```

### 4.2 六大内容创意来源

持续的内容选题从哪来？六个不会枯竭的来源：

```
1. 关键词数据（40% 选题来源）
   → 工具：百度关键词规划师 / 5118 / Ahrefs / Semrush
   → 发现：人们已经在搜什么？
   → 优势：有搜索量数据支撑，不瞎猜

2. 销售通话记录（20% 选题来源）
   → 来源：销售团队跟客户的真实对话
   → 发现：客户反复问什么？什么让客户犹豫？
   → 优势：最真实的需求——而且竞品拿不到这些数据

3. 客服反馈 / 用户问卷（15% 选题来源）
   → 来源：客服聊天记录、NPS 调查回访
   → 发现：用户最困惑的功能、最多的投诉
   → 优势：直接反映"使用中"的痛点

4. 论坛/社区挖掘（10% 选题来源）
   → 来源：知乎/小红书/Reddit/行业论坛
   → 发现：人们在讨论什么但没有好答案？
   → 优势：找到"需求存在但供给不足"的话题

5. 竞品内容分析（10% 选题来源）
   → 来源：竞品的博客、白皮书、社交内容
   → 发现：竞品在写什么？他们漏了什么？
   → 优势：快速建立基准线 + 找到差异化角度

6. 内部专业知识（5% 选题来源）
   → 来源：创始人的行业洞察、工程师的技术博客
   → 发现：只有你们知道但外面人不知道的事
   → 优势：独特性最强，竞品无法复制
```

## 5. 结构拆解：战略规划型 Skill 模板

```markdown
## 战略规划型 Skill 模板

### 核心特征
→ 输出是"计划"而非"内容"（战略型而非执行型）
→ 核心决策 = 二分法（简化判断）
→ 关键设计 = 选题池 + 优先级评分 + 日历规划

### 通用结构

## Decision Framework（决策框架）
- 核心二分/三分法：[分类维度]
- 比例建议：[各类占比 + 理由]

## Content Architecture（内容架构）
- Pillar-Cluster（支柱-集群 内容模型）模型：[Hub-and-Spoke（轮毂-辐条 内容结构） 结构]
- 支柱体系示例：[行业定制]

## Priority System（优先级系统）
- 评分维度：[各维度权重 + 评分标准]
- 创意来源：[N 个持续产出选题的来源]

## Editorial Calendar（内容日历）
- 频率：[发布节奏]
- 主题分配：[搜索型 vs 分享型的周分布]
```

**什么时候用战略规划型？** → 当 Skill 的输出是"决策"和"计划"而非"执行产物"时：内容策略、发布计划、营销日历、产品路线图——任何"先规划后执行"的场景。战略型 Skill 通常在上游，为下游的执行型 Skill 提供方向。

## 6. 电商案例：母婴店天猫+小红书双渠道30天内容作战计划

> 🛒 **实战案例**：「贝初」母婴品牌（主打 0-3 岁宝宝辅食机，天猫旗舰店+小红书企业号双渠道运营），准备在"618 年中促"前 30 天做一波内容预热——核心目标是让品牌在妈妈群体中建立"辅食机=贝初"的心智。团队 1 个内容运营 + 1 个设计，之前按"灵感"发内容——今天发育儿干货、明天发产品促销、后天转发专家文章，内容之间无逻辑，小红书笔记平均互动 80-150，天猫内容频道几乎没流量。
>
> **用 content-strategy Skill 制定 30 天内容作战计划（5 月 18 日-6 月 17 日）**：
>
> | 阶段 | 时间段 | 搜索型内容（天猫+小红书 SEO） | 分享型内容（小红书社交传播） | 比例 |
> |------|--------|--------------------------|--------------------------|------|
> | 预热期 | 5/18-5/28（11天） | Pillar 1「6-12 月宝宝辅食全攻略」+ 3 篇 Cluster（"高铁米粉怎么选""辅食添加顺序和排敏""南瓜/山药/西兰花菜泥教程"）| 1 篇「儿科医生：90% 的妈妈第一口辅食都喂错了」 | 4:1 |
> | 种草期 | 5/29-6/10（13天） | Pillar 2「辅食机选购避坑指南」+ 3 篇 Cluster（"辅食机 vs 破壁机 vs 料理棒""8 分钟做出细腻菜泥的秘密""妈妈群 500 人票选的辅食机 TOP5"）| 2 篇「婆婆嫌我买辅食机浪费钱，一周后她偷偷自己用」+「宝宝第一次吃自己做的南瓜泥，表情太治愈了」 | 3:2 |
> | 爆发期 | 6/11-6/17（7天） | 2 篇搜索型「618 辅食机价格走势预测」「贝初辅食机横评（与竞品参数对比）」 | 2 篇「618 我买了贝初辅食机，理由只有一条」+ 真实用户宝宝吃饭视频征集 | 2:2 |

> **效果（618 结束后复盘）**：
> - 预热期：「高铁米粉怎么选」SEO 长文发布第 7 天进入天猫搜索"宝宝米粉"第 3 名，日均引流 420 UV（UV：独立访客） → 带动辅食机关联销售 68 台
> - 种草期：「婆婆嫌我浪费钱」笔记在小红书获赞 3,200+、收藏 2,800+，评论区 UGC（UGC：用户生成内容）自发讨论辅食机选购，品牌自然搜索量上涨 4 倍
> - 爆发期：「618 辅食机价格走势预测」被小红书官方收入"618 必看攻略"合集，曝光 12 万+
> - 30 天总效果：天猫旗舰店自然搜索GMV（GMV：商品交易总额）从日均 ¥1,800 → ¥7,200（+300%），小红书企业号粉丝从 860 → 5,400（+528%）

> 🔑 **启示**：好的内容策略不是"多发"，而是"行军打仗一样部署时间线"。预热期打地基（SEO 文章慢慢涨排名）、种草期创造社交传播（爆款笔记放大声量）、爆发期收割（价格/竞品对比帮用户做最后决策）。Pillar-Cluster（支柱-集群 内容模型）让 10 篇文章互相增强——用户搜"高铁米粉"进入 Cluster 文章，被内链引到 Pillar 辅食全攻略，再被跳转到辅食机产品页——每一步都在加深购买意图。

**Q1**：**B** —— 可搜索内容捕获已有需求（用户主动搜索），靠搜索引擎持续获取流量；可分享内容创造新需求（用户看到后被激发兴趣），靠社交平台传播获取爆发增长。关键区别是需求是否已经存在。

**Q2**：**C** —— 搜索型:分享型推荐约 6:4 或 7:3。大部分是"资产型"可搜索内容（持续产生搜索流量），少部分是"彩票型"可分享内容（赌爆发传播）。先建搜索资产"保底"，再用分享内容"冲高"。

**Q3**：参考答案——Pillar Page 是主题完整指南（如《2026 年养猫完全指南》），讲全貌和目录。Cluster 是围绕支柱的子主题文章，深入展开一个点，通过内链与 Pillar 相连。宠物用品电商示例见课程 §3.2。

**Q4**：参考答案——对人：任何新选题一秒判断"搜的还是转的"，没有第三种可能，不纠结。对 AI：一分判断后整个后续策略自动匹配，不会在分类阶段消耗大量判断力。多分类法边界模糊且容易出错。

**Q5**：**C** —— 包含反常识结论（争议性）+ 个人投入（信任感），是典型的可分享内容。A、B、D 都是搜索型内容。

**Q6**：参考答案——问题：所有内容都是搜索型，缺少可分享内容。导致(1)流量全靠搜索引擎；(2)没有社交传播扩大漏斗顶部；(3)流量天花板被搜索量框死。改进方案：加入 25-30% 的分享型内容，搜索型内容建立 Pillar-Cluster（支柱-集群 内容模型）体系互相增强。

**Q7**：参考答案——销售通话记录和客服反馈最易找到独特角度。原因：(1)非公开信息源——竞品看不到；(2)直接反映真实客户的真实困惑和真实用词；(3)能发现"客户反复问但网上没人写清楚"的内容空白。

**评分**：答对 5/7 = 通过。
