# L3-09：邮件追销序列 —— 序列思维 + 四大原则 + 六类邮件体系

> 🎯 **学什么**：学会设计完整的自动邮件序列——不是一封一封写，而是作为一条"时间线"来设计，让每封邮件在对的时间说对的话。核心洞察：序列思维 vs 单封思维——单封思维像你追一个人，每次发消息都是"在吗？约吗？"序列思维像你跟她建立一段关系：先认识、再了解、再建立信任、最后才邀请约会。每封邮件只做一件事，先给价值再提要求。
> 💡 **难易度**：⭐⭐ | ⏱️ **预计时间**：40 分钟

***

## 1. 课程概览

> 💡 **白话小课堂**：这个 Skill 就像一个**自动追客户的机器人管家**——用户留了联系方式但没有买。你不是每天去敲他家门喊"买吧买吧"，而是设计了一整套自动流程：Day 0 先发欢迎信+送小礼物、Day 3 给他看别人用了之后的好评、Day 7 消除他的顾虑、Day 14 最后邀请他下单。整个过程全自动——你不用管，机器人管家按时按节奏帮你追。

> **本课的独特定位**——序列设计型 Skill：

| 特征 | L3-05（转化文案） | L3-09（本课） |
|------|-----------------|-------------|
| 粒度 | 单页面文案 | **多封邮件的时间线** |
| 核心思维 | 页面结构顺序 | **序列节奏设计** |
| 时间维度 | 一次性阅读 | **数天~数周的递进** |
| 关键原则 | 五大原则（清晰>巧妙） | **四大原则（一封一事+先给价值）** |

> 🔑 **核心秘诀**：邮件序列最关键的洞察是"一封邮件一件事"（One Email, One Job）。你打开收件箱，找一封同时让你"查看新功能""看案例""参加活动""升级套餐"的邮件——你做了什么？什么都没做。因为用户被多个CTA（CTA：行动号召） 困扰时，决策疲劳让他们的默认行为是"什么都不做"。一个 CTA（CTA：行动号召） 让用户明确知道"你要我做什么"，三个 CTA（CTA：行动号召） 让用户觉得"你自己都没想清楚"。

> ⚠️ **避坑指南**：违反"一封邮件一件事"是最常见的错误。一封邮件里塞了 3 个 CTA（CTA：行动号召）——查看新功能 + 看案例 + 升级套餐——用户不知道该点哪个，结果什么都没点。

## 2. 序列思维 vs 单封思维

### 2.1 本质区别

```
单封思维（❌ 错误）：
  每次写一封邮件 → 想到哪写到哪
  → 堆砌功能、没有节奏、用户疲劳
  → 就像你追一个人，每次发消息都是"在吗？约吗？"
  → 对方：这人是不是只想推销？

序列思维（✅ 正确）：
  先设计整条序列架构 → 多少封、什么节奏、每封什么任务
  → 一封邮件只做一件事、先给价值后提要求、相关性优先于数量
  → 就像你跟她建立一段关系：认识→了解→信任→邀请
  → 对方：这个人懂我
```

### 2.2 序列架构师的思维模型

在做任何一封邮件之前，先回答：

```
1. 这个序列的目的是什么？
   → 欢迎新用户？培育线索？挽回流失？

2. 需要多少封邮件？
   → 欢迎序列：5-7 封（前密后疏）
   → 培育序列：4-6 封（均匀节奏）
   → 挽回序列：3-4 封（低频温和）

3. 每封邮件只做一件事——这件事是什么？
   → 封 1：欢迎 + 送小礼物（建立关系）
   → 封 2：价值内容（教学/洞察）
   → 封 3：社会证明（别人怎么用的）
   → 封 4：消除顾虑（FAQ/异议处理）
   → 封 5：行动邀请（最终 CTA）

4. 每封邮件间隔多久？
   → 前 3 封密集（趁热度在）→ Day 0、Day 2、Day 4
   → 后几封拉开（避免骚扰）→ Day 7、Day 12、Day 18
```

## 3. 四大核心原则详解

### 3.1 原则 1：一封邮件一件事（One Email, One Job）

```
这是最容易违反的原则。

为什么容易违反？
  → 你觉得"用户难得打开我的邮件，我要多塞点东西"
  → 你觉得"这几件事都很重要，不能取舍"
  → 你觉得"只有一个CTA（CTA：行动号召）太浪费了"

违反的后果：
  → 用户看着 3 个 CTA（CTA：行动号召），不知道该点哪个
  → 决策疲劳（Decision Fatigue）→ 默认选择：什么都不点 → 关掉邮件
  → 不是邮件被屏蔽了，是用户的行为被"选择困难"阻止了

正确的做法：
  → 每封邮件 = 1 个明确的目标 +1 个CTA（CTA：行动号召）
  → 如果确实有 3 件事要说 → 设计 3 封邮件，各说各的
  → 宁可多发一封，不要在一封里塞两件事
```

### 3.2 原则 2：先给价值再提要求（Value Before Ask）

```
这是序列设计的核心原则。

错误的 Day 0 邮件：「订阅吧，只要 ¥129/月！」
  → 用户心理：「我茶都还没喝到嘴里，你就要我掏 129 元？凭什么？」
  → 价值感和信任感还没建立就提要求
  → 违反了社交交换原则——你先付出价值，对方才觉得"欠你一次"

正确的 Day 0-10 的设计：
  Day 0：欢迎 + 送免费试喝小样包（3 泡茶包邮）→ 给价值
  Day 3：「3 个不花一分钱的茶叶保存秘诀」→ 给价值
  Day 7：「云南古树茶农的故事」→ 给情感价值
  Day 10：「其他茶友怎么评价我们的茶」→ 给社会证明
  Day 14：首次提订阅邀请 → 现在才提要求

为什么前 4 封都不提要求？
  → 这 4 封在积累"社交资本"——你给了用户 4 次价值
  → 到 Day 14 时，用户已经从"陌生人"变成了"了解你、信任你的人"
  → 此时提订阅 = 水到渠成而非强行推销
  → 心理学原理：互惠原则（Reciprocity）——你先给，他才会想回馈
```

### 3.3 原则 3：相关性优于数量（Relevance Over Volume）

```
错误：每周 3 封群发邮件给所有人
  → 新用户收到"老用户回归福利"
  → 活跃用户收到"欢迎入门指南"
  → 休眠用户收到"新功能发布"
  → 所有人收到跟自己无关的内容 = 退订

正确：按用户行为分群，每群收到相关内容
  → 刚注册 → Welcome 序列（引导到 Aha（Aha：用户顿悟时刻）时刻）
  → 活跃用户 → 每月 1-2 封升级引导
  → 30 天不活跃 → Re-engagement 序列
  → 下载了资料没买 → Lead Nurture 序列

核心：宁可少发，不要发给错的人。
    1 封收到相关邮件的用户 > 10 封收到垃圾邮件的用户
```

### 3.4 原则 4：前密后疏（Dense Start, Sparse Later）

```
节奏设计的科学依据：

Welcome 序列（刚注册时）：
  用户热度最高（像刚加微信好友的 24 小时）
  → Day 0: 立即发送（欢迎 + 首个价值）
  → Day 1-2: 第二封（加深连接）
  → Day 3-4: 第三封（趁热）
  为什么前半段密集？
  → 这段时间用户的打开率和互动率最高
  → 趁热度在的时候建立强连接
  → 像刚认识一个人——前三次见面的印象决定了关系走向

后半段拉开：
  → Day 7: 第四封
  → Day 12: 第五封
  → Day 18-21: 最后一封
  为什么后半段稀疏？
  → 如果持续密集，用户会烦——像刚认识就每天发消息
  → 拉长间隔 = 尊重用户的空间，但保持存在感

Lead Nurture 序列节奏不同：
  → 用户还没建立强烈的品牌连接，热度较低
  → 节奏更均匀——每封邮件之间给更多消化时间
  → 不能用 Welcome 序列的"前密"策略轰炸
```

## 4. 六类邮件序列体系

### 4.1 什么时候发什么序列

```
邮件分类体系（6 大类）：

1. Onboarding（上手引导）
   触发：用户刚注册
   目标：帮用户到达 Aha（Aha：用户顿悟时刻）时刻
   节奏：前密后疏（Day 0/2/4/7/12/18）
   不能搞混：给休眠用户发"欢迎入门"=奇怪

2. Retention（用户留存）
   触发：用户在活跃使用
   目标：加深使用习惯 + 发现新价值
   节奏：低频（每月 1-2 封）

3. Billing（计费相关）
   触发：试用到期 / 续费提醒 / 发票
   目标：确保付费流程顺畅
   节奏：按事件触发（非周期性）

4. Usage（使用引导）
   触发：用户未使用某些功能
   目标：发现产品的更多价值
   节奏：按行为触发

5. Win-Back（流失挽回）
   触发：用户 30-90 天未活跃
   目标：重新激发兴趣
   节奏：低频温和（3-4 封 / 2 周）
   不能搞混：给新手发"我们想你了"=莫名

6. Campaign（营销活动）
   触发：促销/活动/新品发布
   目标：特定营销目标
   节奏：按活动周期
```

### 4.2 邮件结构模板

每封邮件的 5 个组成部分：

```
1. Hook（钩子）— 1 句话吸引打开
   → "昨天晚上，你泡了上个月那盒龙井——有没有觉得味道变了？"
   → 不要写： "我们的茶叶很棒"——这是废话
   → 要像你跟小孩子说话一样先蹲下来"嘿你看这是什么？"

2. Context（上下文）— 1-2 句说明为什么发这封邮件
   → "茶叶跟红酒一样，保存方式完全影响风味。"
   → 用户需要知道"这封邮件跟我有什么关系"

3. Value（核心价值）— 邮件的主体内容
   → 教学、洞察、故事、数据——你给用户的"东西"
   → 这是你在积累社交资本

4.CTA（CTA：行动号召）（行动召唤）— 1 个明确的下一步
   → "点击这里领取免费茶样"（而不是 3 个按钮）
   → 用户需要明确知道"现在你该做什么"

5. Sign-off（签名）— 人味
   → 真实姓名 + 职位 + 一个小小的个人化细节
   → 邮件是"人发给人的"而非"系统自动发的"
```

## 6. 电商案例：护肤品牌弃购用户 6 封追销邮件序列

> 🛒 **实战案例**：天猫「肌研日记」护肤品旗舰店，用户将"积雪草修护精华液 ¥198"加入购物车但未支付——弃购率 67%（100 人加购，67 人未付款就离开了）。之前只有 1 封自动追销短信（"你购物车里的精华液还在等你哦"），召回率仅 2.3%。67% 的弃购意味着每月约 3,200 人在最后一步流失——这不是流量问题，是"犹豫的人需要多推一把"的问题。
>
> **用 email-sequence Skill 设计 6 封弃购追销序列（时间锚定：弃购后 1h/24h/3d/7d/14d/30d）**：
>
> | 时间 | 邮件主题 | 做什么（One Email, One Job） | 原则 |
> |------|---------|--------------------------|------|
> | 弃购后 1h | 「你的精华液还在购物车等你～」 | **温和提醒 + 快捷支付链接**，不提促销（用户在犹豫，信息太复杂反而干扰） | 一封一事（只做"提醒"） |
> | 弃购后 24h | 「327 位敏感肌是怎么用这瓶精华的？」 | **社会证明**——3 条真实用户 15 秒视频评价+前后对比图，展示"别人用了有效果" | 先给价值（用户证言=信任资产） |
> | 弃购后 3d | 「敏感肌自救指南（不买也能看）」 | **价值内容**——免费给<敏感肌日常护理 5 步法>PDF，先教不卖 | Value Before Ask（先付出） |
> | 弃购后 7d | 「你可能在担心的 3 件事」 | **异议处理**——"会不会过敏？""没用能退吗？""和普通精华有什么区别？"三个问题逐一解答 | 一封一事（只做"消顾虑"） |
> | 弃购后 14d | 「今天下单多送 3 片试用装（仅限今天）」 | **限时激励**：¥198 买精华送 ¥59 试用装+30 天无忧退 | 前 4 封积累价值 → 现在给理由 |
> | 弃购后 30d | 「清空购物车提醒——你的精华液即将过期」 | **紧迫感收官**：购物车商品将在 3 天后自动清除，最后一次提醒 | 一封一事（最后一次机会） |
>
> **效果**：
> - 弃购追销序列召回率：2.3%（单条短信）→ 14.8%（6 封邮件序列），每月挽回约 474 单
> - 前 4 封的打开率变化：1h 邮件 62% → 24h 邮件 51% → 3d 邮件 43% → 7d 邮件 38%（远高于行业促销邮件平均 18-22%）
> - 关键发现：24h 邮件（社会证明视频）的转化贡献最大——占序列总转化量的 31%。用户看到真实视频后疑虑消散
> - 30d 封邮件的转化率仅 1.8%，但"最后一次机会"的措辞使退订率极低（0.3%）——用户觉得你在帮他而不是骚扰

> 🔑 **启示**：弃购用户不是"不想买"，是"还没下定决心"。序列思维的关键是节奏——1h 温和提醒（别吓到他）、24h 视频证明（让他看到别人用了好）、3d 免费教他（你值得信任）、7d 解答顾虑（你想过的问题我都回答了）、14d 才开始给购买激励（前面 4 封的信任积累让赠品显得真诚而非套路）、30d 温柔告别（不买没关系，帮你清空购物车）。6 封邮件 = 一个从"陌生人"到"信任者"的 30 天关系建立。

## 8. 答案

<details>
<summary>点击查看答案</summary>

**Q1**：**B** —— 一封邮件里有多个CTA（CTA：行动号召） 时，用户不知道该点哪个，结果什么都没点。不是邮件被屏蔽，而是用户的行为被"决策疲劳"阻止了。

**Q2**：参考答案——Welcome 序列（刚注册）采用"前密后疏"：Day 0/2/4 密集发送，趁用户热度最高时建立连接；后期拉长到 3-5 天一封。Lead Nurture 序列（下载资料后）节奏更均匀——用户热度较低，不能用密集轰炸。

**Q3**：参考答案——如果 Day 0 就要求订阅，用户心理："我茶都还没喝到，你就要我掏 ¥129？凭什么？"核心是价值感和信任感还没建立。实际设计的前 4 封都在积累"社交资本"——教冲泡、讲故事、展示评价。到 Day 18 时用户已经从"陌生人"变成了"信任品牌的懂茶人"，订阅邀请是"水到渠成"。心理学原理：互惠原则——你先给，他才想回馈。

**Q4**：**C** —— 下载了资料→Lead Nurture 序列。A 错：刚注册→Welcome 序列。B 错：不活跃→Re-engagement 序列。D 错：刚购买→Post-Purchase 序列。

**Q5**：参考答案——Hook："昨天晚上，你泡了上个月那盒龙井——有没有觉得跟上次味道不一样？" Context："茶叶跟红酒一样，保存方式完全影响风味。很多茶友不知道，绿茶开封后 30 天内如果不妥善保存，香气会损失 40%。"

**Q6**：参考答案——问题：(1) 违反"One Email, One Job"——每周 3 封统一邮件内容杂乱；(2) 违反"Relevance Over Volume"——没按用户分层；(3) 缺少序列思维。改进：按用户行为分群，每群独立序列，每封只做一件事，先给价值再提要求。

**Q7**：参考答案——刚注册 2 天未完成设置→Onboarding 序列（引导到达 Aha（Aha：用户顿悟时刻）时刻）。3 个月不活跃→Win-Back 序列（重新激发兴趣）。不能搞混：内容不同（引导 vs 挽回）、节奏不同（前密后疏 vs 低频温和）、CTA 不同（"完成下一步" vs "回来试试"）。

**评分**：答对 5/7 = 通过。
