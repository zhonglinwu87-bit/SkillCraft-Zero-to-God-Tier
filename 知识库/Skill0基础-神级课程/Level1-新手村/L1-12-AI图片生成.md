# L1-12：AI 图片生成 —— Prompt 工程在 Skill 中的落地

> 🎯 **学什么**：如何把「写好 Prompt」的方法论固化为 Skill——Prompt 七要素公式 + 场景模板 + 变量替换。核心洞察：不让用户从零写 Prompt，而是提供「填空题」——用户填 2-3 个变量，AI 补全剩下的技术细节。
> 💡 **难易度**：⭐ | ⏱️ **预计时间**：35 分钟

***

## 1. 课程概览

> 💡 **白话小课堂**：AI 本身就能生成图片——但你直接说「帮我做一个好看的图」，它可能出个花花绿绿不知所云的东西。L1-12 教的 image Skill 就像给你一个「拍照公式」——主体、风格、构图、光线、配色、氛围、技术参数，七要素全想起来，每次出图都很靠谱。更重要的是——**用户不需要学 Prompt Engineering**。Skill 提供的是「填空题」：产品名填这里、风格选那个、场景选这个——剩下的技术参数 AI 自动补全。

> **本课的独特定位**——Prompt 工程的「模板化」落地：

| 做法 | AI 自由发挥 | Prompt 公式（本课） |
|------|-----------|-------------------|
| 用户输入 | 「帮我做张好看的图」 | 「产品：智能咖啡机，场景：现代厨房，风格：写实摄影」 |
| AI 输出 | 随机风格，质量不稳定 | 七要素齐全，品质可控 |
| 可复现性 | 几乎为零 | 公式 + 参数 = 可复现 |

> 🔑 **核心秘诀**：七要素公式就像菜谱——不是你每次都要用全部七个，但如果你缺了「盐」（比如忘了说风格），出来的图可能就差一截。好的 Prompt Skill 确保「每次至少把七个要素都想过」。

> ⚠️ **避坑指南**：不要把用户变成 Prompt Engineer（提示词工程师——需要精通如何给 AI 写指令的专业角色）。如果 Skill 要求用户「请描述你想要的构图、光线、配色方案……」，用户会直接放弃。正确做法是「填空题模式」——用户提供业务变量（产品名、场景、风格偏好），AI 负责把技术参数（85mm lens, f/2.8, natural light）补全。

## 2. Prompt 七要素公式详解

### 2.1 为什么需要七要素？

```
AI 自由发挥的 Prompt（不可控）：
  「帮这张咖啡机的图做得好一点」
  → AI：可能出写实摄影，也可能出卡通插画，也可能出 3D 渲染
  → 三次生成，三张完全不同的风格
  → 问题：没有约束就没有一致性

七要素公式驱动的 Prompt（可控）：
  Subject: 智能咖啡机，不锈钢拉丝表面，蒸汽从喷嘴升起
  Style: photorealistic product photography, interior design magazine quality
  Composition: rule of thirds, coffee machine on left, negative space on right for copy
  Lighting: soft morning natural light, window side, gentle shadows
  Color palette: warm earth tones, brushed steel, cream whites
  Mood: cozy morning ritual, aspirational lifestyle
  Technical: 1200x630, WebP, 85mm lens, f/2.8, shallow depth of field
  → 每次生成都高度一致
```

### 2.2 七要素逐个拆解

| # | 要素 | 作用 | 如果漏了会怎样 | 典型值 |
|---|------|------|-------------|--------|
| 1 | **Subject** | 画面主体是什么 | AI 不知道焦点在哪——咖啡机可能偏到角落去 | 产品名 + 核心特征 + 材质 |
| 2 | **Style** | 视觉风格/画风 | AI 随机选风格——照片/插画/3D 都有可能 | photorealistic, watercolor, flat-vector |
| 3 | **Composition** | 主体在画面中的位置 | 构图随机——可能歪可能偏 | rule of thirds, centered, negative space |
| 4 | **Lighting** | 光线方向和质感 | 光线平淡——画面没有立体感 | natural morning light, studio lighting, golden hour |
| 5 | **Color palette** | 色调和色彩倾向 | 颜色可能刺眼或不协调 | warm earth tones, cool blues, monochrome |
| 6 | **Mood** | 画面传达的情绪 | 没有情绪——看起来像产品目录 | cozy, energetic, luxurious, calm |
| 7 | **Technical** | 尺寸、格式、镜头参数 | 尺寸不对——发小红书裁掉标题 | 1200x630, 85mm lens, WebP |

> 🔑 **设计要点**：七个要素分类不是 AI 研究者拍脑袋分的——它们映射到图像生成的七个可独立控制的维度。其中 Composition（构图）对于「文案图片」尤其重要——Blog Hero 是横向宽图，标题文案要放左边还是右边？构图决定了文案的空间。

### 2.3 七要素公式作为 Skill 设计模式

七要素公式可以推广到任何「从模糊需求到精确指令」的 Prompt Skill 设计：

```
通用模式：
1. 识别生成任务的关键维度（图片=7 个，文案=5 个，代码=4 个）
2. 为每个维度定义可选值或自动推导规则
3. 用户只填业务变量（产品名、平台、目标受众）
4. AI 自动补全所有技术维度
5. 输出完整的结构化 Prompt
```

**可推广场景**：
- 图片生成：七要素公式（本课）
- 广告文案生成：产品+受众+平台+角度+长度五要素
- 代码生成：语言+框架+功能+输入输出+性能要求五要素
- 邮件生成：收件人+目的+价值+CTA+语调五要素

## 3. 场景模板 + 变量替换 —— 批量化 Prompt 的核心策略

### 3.1 为什么是「填空题」而不是「写作文」？

```
「写作文」模式（用户从零写 Prompt）：
  要求：用户懂 Prompt Engineering
  问题：大多数营销人员不懂什么是「85mm lens, f/2.8」
  结果：「帮我做张好看图」→ 质量不可控

「填空题」模式（用户填 2-3 个变量）：
  模板：{产品名} placed on a {材质} surface in a bright {风格} style {房间}
  用户填：智能咖啡机 / 大理石 / 北欧 / 厨房
  AI 补全：natural morning light, shot on 85mm lens, 3:4 aspect ratio
  结果：每次都包含全部七要素，质量可控
```

### 3.2 场景模板的设计原则

```
Blog Hero 模板（1200×630 横向）：
  {产品或主题} shown in {场景}, {风格} style.
  {光线描述}. Ample copy space on {左或右} for text overlay.
  Shot on 85mm lens, 1200x630, WebP.

  → 关键设计：Composition 特意留了 copy space——因为 Blog Hero 上面要放标题

Social Post 模板（1080×1080 方形）：
  {产品或主题} centered in frame, {风格} aesthetic.
  {光线描述}, {配色}. Aspirational lifestyle photography.
  1080x1080, 1:1 aspect ratio.

  → 关键设计：方形构图，主体居中（社交媒体信息流的最佳展示方式）

Product Mockup 模板：
  {产品名} on a clean {材质} surface, product photography style.
  Studio lighting, no shadows on background. White/transparent background.
  2000x2000, PNG, product takes 80% of frame.

  → 关键设计：干净背景 + 产品占画面 80%——电商产品图的黄金比例
```

### 3.3 批量生成的变量替换

对于大批量场景（如 500 个产品的场景图），模板 + 变量替换是核心策略：

```
不是为每个产品手写 Prompt：
  ❌ 产品 A：「智能咖啡机在明亮的北欧厨房，自然晨光…」
  ❌ 产品 B：「陶瓷茶杯在明亮的北欧厨房，自然晨光…」
  ❌ 产品 C：「不锈钢锅在明亮的北欧厨房，自然晨光…」
  → 500 个产品 = 500 个手写 Prompt，不可能

而是用模板 + 变量：
  ✅ 模板：「{产品名} placed on a {材质} surface in a bright {风格} style {房间}, natural morning light, shot on 85mm lens, 3:4 aspect ratio」
  ✅ 产品 A：智能咖啡机 / 大理石 / 北欧 / 厨房
  ✅ 产品 B：陶瓷茶杯 / 木质 / 日式 / 茶室
  ✅ 产品 C：不锈钢锅 / 花岗岩 / 现代 / 厨房
  → 500 个产品 = 1 个模板 + 500 组变量，脚本自动批量生成
```

> 🔑 **设计要点**：模板 + 变量替换的模式，与 L1-05 的「Prompt 落文件」铁律完美配合——模板本身就是 Prompt 文件，变量替换后生成 500 个独立 Prompt 文件，可审查、可迭代、可复现。批量 ≠ 随机。

## 4. 结构拆解：Prompt 工程型 Skill 模板

从 L1-12 提取「Prompt 工程型」Skill 的通用模板：

```markdown
## Prompt 工程型 Skill 模板

### 核心特征
→ 输出 = 结构化的 Prompt 文本（不是图片/代码/文章本身）
→ Skill 不直接调生成 API——生成由后续工具完成
→ 核心价值 = 把模糊需求转化为精确的 Prompt 指令

### 通用结构

## Prompt Formula（要素公式）
Dimension 1: [名称] — [作用] — [默认值/自动推导规则]
Dimension 2: [名称] — [作用] — [默认值/自动推导规则]
...
Dimension N: [名称] — [作用] — [默认值/自动推导规则]

## Scene Templates（场景模板）
### Template A: [场景名]
{变量1} + {变量2} + {变量3} → [完整 Prompt]
[适用场景] [关键设计考量]

### Template B: [场景名]
...

## Variable Substitution（变量替换规则）
变量来源 → 映射到哪个要素 → 默认值

## Output
[完整 Prompt 文本，标注变量来源和要素覆盖情况]
```

**什么时候用 Prompt 工程型？** → 当 Skill 的核心价值是「帮用户把模糊需求转化为 AI 可执行的结构化指令」时：图片 Prompt、广告文案 Brief、代码生成 Spec、设计需求文档——任何需要把「我想做个 X」翻译成「具体怎么做 X 的完整指令」的场景。

## 5. 电商案例：美妆产品场景图AI批量生成——从白底到"使用场景"

> 🛒 **实战案例**：某国货彩妆品牌有200个SKU——口红、眼影盘、粉底液、散粉——所有商品图都是白底棚拍。运营发现小红书和抖音上的种草内容，场景化展示（"涂着这支口红喝咖啡"）的点击率比白底图高3倍。但请摄影师为200个SKU逐一搭场景拍摄，预算¥80,000+，周期2个月——新品牌根本扛不住。
>
> **用 image Skill + Midjourney 搭建AI场景图生成流水线**：
>
> **Step 1：设计品类专属场景模板（七要素公式）**
> - **口红**：Subject=口红在化妆台镜前 / Style=photorealistic beauty editorial / Composition=产品占画面60%，浅景深 / Lighting=vanity mirror warm light / Color palette=玫瑰金+象牙白 / Mood=luxurious morning routine / Technical=1080×1080
> - **粉底液**：Subject=粉底液在浴室自然光下 / Lighting=soft diffused bathroom light / Mood=fresh clean beauty
> - **眼影盘**：Subject=眼影盘打开状态在化妆刷旁 / Composition=产品居中，色彩飞散效果 / Mood=creative makeup play
>
> **Step 2：每个品类1个模板 + 每个产品改2个变量**
> - 模板：`{产品名} in a {场景}, {光线描述}, shot on 85mm lens, product photography, {品牌色调}`
> - 口红A（玫瑰豆沙色）→ 场景=vanity mirror morning light / 品牌色调=rose gold
> - 口红B（橘棕色）→ 场景=sunset window sill / 品牌色调=warm terracotta
>
> **Step 3：批量生成 + 质量筛选**
> - 200个产品×3张备选=600张图，分2天生成（控制API速率）
> - 约80%直接可用，15%需微调prompt，5%重做
>
> **效果**：
> - 成本：AI生成<¥1,500（Midjourney月费）vs 实拍¥80,000+（**节省98.1%**）
> - 时间：2天 vs 2个月（**快30倍**）
> - 小红书场景图点击率从白底图的3.7% → 9.2%（+149%）
> - 详情页加入场景图后转化率从4.2% → 6.1%（+45%）
>
> > 🔑 **启示**：美妆卖的不是产品是"用了之后的我"。白底图告诉用户"这是什么"，场景图告诉用户"用了这个你会成为谁"。AI场景图的核心效率不在"替代摄影师"，而在"为200个SKU各做3个场景"——这个量级靠实拍永远做不完。模板+变量替换让200个产品的Prompt生成从"不可能"变成"改2个变量就行"。

## 6. 掌握检验

**Q1**：image Skill 的 Prompt 七要素公式中，「Composition（构图）」指的是什么？
- A) 图片的文件格式和分辨率
- B) 主体在画面中的位置安排，如 rule of thirds（三分法则）、centered（居中）、negative space（留白）
- C) 图片的色彩方案，如暖色调或冷色调
- D) 主体的物理大小

**Q2**：AI 本身就能生成图片 prompt，为什么还需要专门的 image Skill？列出三个原因。

**Q3**：场景化 Prompt 模板（如 Blog Hero 和 Social Post）为什么设计成「填空题」模式（用户只填 2-3 个变量），而不是让用户从零写完整的 prompt？

**Q4**：请为以下场景补全 Prompt 七要素公式中缺失的部分：
- Subject：智能咖啡机
- Style：photorealistic
- Composition：？（填空）
- Lighting：soft morning light, kitchen window
- Color palette：warm earth tones
- Mood：cozy morning ritual
- Technical：1200x630, WebP

**Q5**：某家居品牌用 image Skill 批量生成 500 个产品的场景图。以下哪项正确描述了批量化 prompt 的核心策略？
- A) 为每个产品手写一个完全不同的 prompt
- B) 使用场景模板 + 变量替换——`{产品名} placed on a {表面材质} surface in a bright {风格} style {房间类型}`，只需替换 3 个变量
- C) 用一个通用 prompt 套用所有产品
- D) 随机生成 prompt，挑最好的用

**Q6**：Blog Hero 和 Social Post 的 Prompt 模板在尺寸（aspect ratio）上有什么不同？为什么不同？构图（Composition）要素如何呼应尺寸差异？

**Q7**：Prompt 七要素公式可以推广到什么类型的 Skill？请举一个非图片生成的例子，说明你会如何设计类似的「多要素公式」。

## 7. 答案

<details>
<summary>点击查看答案</summary>

**Q1**：**B** — Composition 是构图的英文，指主体在画面中的位置安排方式：三分法则（rule of thirds）、居中（centered）、留白（negative space）等。A 指的是 Technical（技术参数），C 指的是 Color palette（配色），D 不在七要素中。

**Q2**：三个原因：1) **标准化质量**——确保每次生成的 prompt 都包含所有关键要素（七要素公式），避免用户随口说「帮我做个好看图」导致结果不可控；2) **面向场景**——不同场景（Blog Hero、Social Post、Product Mockup）用不同的 prompt 模板和公式，而非一刀切；3) **降低使用门槛**——用户不需要学 Prompt Engineering，只需填业务变量（产品名、场景），AI 负责补全所有技术要素（构图、光线、配色、镜头参数）。

**Q3**：用户通常不会（也不该需要）从零构思 prompt——这是专业设计师/提示词工程师的技能。填空题模式让用户只需要提供业务变量（产品名、使用场景），AI 负责补全所有技术要素（构图、光线、配色、技术参数）。这降低了使用门槛（营销人员不需要学 prompt engineering），同时保证了输出质量（AI 确保七要素齐全）。好比填税表——用户填数字，会计处理剩下的所有技术细节。

**Q4**：Composition 可能的合理答案：**rule of thirds with coffee machine on left, steam rising, negative space on right for copy**（三分构图，咖啡机在左侧，蒸汽上升，右侧留白放文案）。对于 Blog Hero 模板，1200×630 的横向尺寸意味着需要在左右方向留文案空间（ample copy space），所以构图应将主体偏向一边，另一边留白。这个要素的目的不是「怎么好看」，而是「文案放在哪里」。

**Q5**：**B** — 场景模板 + 变量替换是批量生成的核心策略。使用模板 `{产品名} placed on a {表面材质} surface in a bright {风格} style {房间类型}`，批量操作时只需替换产品名、表面材质、风格和房间类型 3-4 个变量，其余要素保持不变。A 完全手写太慢，C 太通用（不同产品场景不同），D 太随机（不能保证质量）。

**Q6**：Blog Hero 尺寸为 1200×630（横向 16:9），Social Post 尺寸为 1080×1080（正方形）。原因：Blog Hero 用于文章顶部横幅，在网页上以横向宽图展示，需要左右方向的空间放置标题文案；Social Post 用于 Instagram 等社交平台，正方形在信息流中占据最佳视觉面积。构图要素的呼应：Blog Hero 的 Composition 要留 **horizontal** copy space（左边或右边留白给标题），Social Post 的 Composition 要 **center subject**（主体居中，适合方形构图的浏览体验）。

**Q7**：可推广到广告文案生成 Skill。五要素公式：1) **Product（产品）**——核心卖点；2) **Audience（受众）**——目标人群和痛点；3) **Platform（平台）**——平台字符限制和最佳实践；4) **Angle（角度）**——痛点/结果/社交证明/好奇心等；5) **CTA（行动号召）**——期望的行动和低门槛表达。用户只填 2-3 个变量（产品、受众、平台），AI 自动补全角度和 CTA，输出符合平台规范的完整广告文案。

（6/7 通过）
