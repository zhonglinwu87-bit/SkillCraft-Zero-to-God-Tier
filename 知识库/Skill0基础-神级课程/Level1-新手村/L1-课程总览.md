# Level 1：新手村 —— 工具型 Skill 精学

> 🥋 **新手村目标**：掌握最简单的「单一功能 + 脚本调用」型 Skill，能独立创建工具型 Skill。
> **难度**：⭐ | **模式**：工具调用型（模式 6）
> **预计时间**：2 周（每天 1-2 课）

***

## 为什么从这里开始？

这些 Skill 的共同特征：
- **功能单一**：一个 Skill 只做一件事
- **脚本驱动**：核心逻辑在 scripts/ 中，SKILL.md 只是"使用说明书"（SKILL.md：定义 Skill 行为的核心文件，包含 YAML（YAML：一种人类易读的数据格式，用缩进表示层级）头部和正文指令）
- **结构简单**：YAML 短 + 正文短 + 依赖清晰
- **即学即用**：学完一课，你能立刻写出同类型的 Skill

## 新手村毕业标准

完成 17 门课后，你应该能：

- [ ] 读懂任何工具型 Skill 的 SKILL.md
- [ ] 写出带完整 CLI 封装的 Skill
- [ ] 正确使用 `description` 触发动词
- [ ] 理解 EXTEND.md 用户偏好系统
- [ ] 能独立设计并实现一个工具型 Skill（含多工具型和 CLI 型）
