## 为什么这门课值得你学

2026 年，AI Agent 正在吃掉软件。Claude Code、Cursor、Devin 们不再只是"聊天机器人"——它们能写代码、发布应用、运营生意、管理团队。而决定一个 AI Agent 能走多远的，不是模型本身，是它背后装了多少 **Skill**。

但 Skill 不是随便写的。一个能稳定工作的 Skill，需要理解协议规范、交互模式、安全边界、异常处理——这些知识，散落在各个开源仓库的 README 里，没有一门课系统讲过。

**Skill0 大师课就是来解决这个问题的。**

### 这门课的四个核心优势

**① RPG 式渐进体系，不跳步、不劝退**

不是"从入门到放弃"的资源列表。每门课按照认知负荷精确分级：

| 阶段 | 定位 | 你能做什么 |
|------|------|-----------|
| L0 先修课 | 理解 Skill 本质 | 读懂任意 SKILL.md，独立安装使用 |
| L1 新手村 | 工具型 Skill | 写单功能 Skill：压缩图片、提取字幕、联网搜索 |
| L2 学徒工 | 基础模式 | 角色扮演、创意生成、竞品分析 |
| L3 熟练工 | 多步骤流水线 | 决策树、矩阵输出、多平台分发 |
| L4 专家 | 复杂业务 | A/B 测试、灰度发布、安全护栏 |
| L5 大师 | 代码生成 | 前端秒建、MCP 构建、Word/PPT/Excel 生成 |
| L6 宗师 | 企业级体系 | 工程架构、代码审查、安全审计、结对编程 |
| L7 神级 | 分布式系统 | 事件驱动、微服务拆分、数据一致性 |

从"图片压缩"到"分布式一致性"——这条路径不是拍脑袋设计的，每一级都对应真实的职业进阶：工具使用者 → 流程设计者 → 系统架构者。

**② 五步教学法，每门课都一样扎实**

市面上大多数"教程"只是在播客里聊概念，看完还是不会写。Skill0 每门课严格执行 **五步闭环**：

```
源码精读 → 结构拆解 → 手写模仿 → 变体练习 → 掌握检验
```

- **源码精读**：逐行阅读原始 SKILL.md，配合设计意图分析。不是"先看看大概"，是每一行都告诉你"作者为什么这样写"
- **结构拆解**：把 Skill 拆成可复用的骨架模板——下次你写同类 Skill，直接套模板
- **手写模仿**：给你一个空白的题目，凭理解自己写出来，再对照参考
- **变体练习**：换一个平台、换一个场景，验证骨架的通用性
- **掌握检验**：8 道题覆盖从概念到实操，答完就知道自己缺什么

这不是"看完就忘"的速食内容。这是"学完就能写"的技能训练。

**③ 覆盖 2026 年最热门的 Skill 类型，不缺角**

| Skill 类型 | 代表课程 | 为什么热门 |
|-----------|---------|-----------|
| CLI 工具型 | Agent Browser（50+ 命令浏览器自动化） | AI 操作网页的标配 |
| API 封装型 | Tavily（联网搜索套件） | AI 获取实时信息的基础设施 |
| 多工具索引型 | 智能图片压缩 / Gemini 网页抓取 | 单功能即服务的最高效形式 |
| 角色+步骤型 | 营销创意生成、转化文案撰写 | 内容和营销自动化的核心 |
| 防御式搜索型 | 供应商搜索、竞品分析 | 企业采购和竞争情报的刚需 |
| 发送/表单型 | 采购询盘 RFQ | B2B 交易自动化的关键模式 |
| 操作确认型 | 商品上下架、库存管理 | 电商运营自动化的安全范式 |
| 代码生成型 | 前端界面秒生成、MCP 构建器 | 2026 年增长最快的 Skill 类别 |

每一类 Skill 都有属于自己的安全模型、交互模式、失败处理策略。这门课没有漏掉任何一种。

**④ 每课标配三大实战支柱，不是读读就完了**

每一门课都严格包含三个实战锚点，缺一不可：

| 支柱 | 作用 | 示例 |
|------|------|------|
| 🔗 **课程回顾** | 每课结尾都有「延伸阅读」板块，用 Wiki-link 链回前置课程，强制形成"温故知新"的螺旋复习链 | L1-17 链回 L1-16、L1-01、L0-02；L1-10 回顾"脚本驱动型 Skill" |
| 🛒 **电商案例** | 每课配一个真实电商场景实战，把抽象模式落到具体业务——不是"设想一个场景"，是"1688供应商详情页转选品数据库""618大促300张促销卡片4分钟生成""竞品淘宝店新品自动监控"这种你明天就能用的案例 | Level1-7 全部课程均含电商案例，覆盖 1688 / 亚马逊 / TikTok / 速卖通 / Shopify 等主流平台 |
| ✅ **课程作业** | 每课末尾 8 道掌握检验题，从概念理解到场景应用题，答对 7/8 才算过关。每级还有**毕业标准**——达不到就回头重学，不跳级、不放水 | "Q7：某母婴电商团队用这个 Skill 批量处理 200 篇文章时，最关键的设计决策是什么？" |

> 这三根支柱撑起来的不是"课程目录"，是**一套自闭环的练兵系统**——学完、练完、考完，不毕业不让走。

## 使用方式

本仓库为 Obsidian vault，所有笔记均为 Markdown 格式：

```
.
├── README.md              # 本文件
├── SKILL-OPTIMIZER.md     # 元技能：用 AI 诊断和优化 Skill 架构
├── Skill大师课-总纲.md      # 课程总纲与学习路线图
├── VERSION                # 版本号
├── Level0-先修课/          # 3 篇
├── Level1-新手村/          # 17 篇
├── Level2-学徒工/          # 15 篇
├── Level3-熟练工/          # 18 篇
├── Level4-专家/            # 19 篇
├── Level5-大师/            # 26 篇
├── Level6-宗师/            # 46 篇
└── Level7-神级/            # 16 篇
```

- **Obsidian 用户**：直接打开本目录作为 Vault → 享受双向链接和知识图谱
- **非 Obsidian 用户**：任意 Markdown 编辑器（Typora、VS Code、Notion）均可阅读
- **笔记间通过 `[[Wiki-link]]` 互联**，形成可导航的知识网络
