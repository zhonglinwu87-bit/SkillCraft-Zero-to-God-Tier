# L2-14：AI幻灯片魔法师 —— 多步骤流水线 + 模板引擎设计（Level 2→3 过渡课）

> 🎯 **学什么**：Level 2 的压轴课——第一次出现「解析 → 选模板 → 渲染 → 导出」完整四步流水线 + 16 种模板的场景匹配决策。这是 Level 2 复杂性上限、Level 3 复杂性下限——打完这关，你就准备好进 Level 3 了。
> 💡 **难易度**：⭐⭐ | ⏱️ **预计时间**：45 分钟

***

## 1. 课程概览

> 💡 **白话小课堂**：这个 Skill 就像一个会魔法的 PPT 大师——你给它一篇 Markdown（Markdown：纯文本排版格式） 大纲（`# 标题`、`## 每页内容`），它自动解析结构、从 16 种设计模板中选最合适的、渲染成好看的幻灯片、导出为 PPT/PDF。你不需要打开 PowerPoint 一个字一个字排版、选字体、调配色、插图片。从前花 5 小时做一份 PPT，现在花 1 小时打磨内容逻辑，排版全自动。

> **本课的独特定位**——Level 2→3 的桥梁：

| 特征 | Level 2 典型 Skill | L2-14（本课） | Level 3 典型 Skill |
|------|------------------|-------------|------------------|
| 步骤数 | 1-2 步 | **4 步流水线** | 4-7 步 |
| 决策点 | 1-2 个分支 | **16 种模板选择** | 多个决策树 |
| 参考资料 | 简单配置 | **references/ 矩阵** | 大量 references |
| 复杂度 | 单一维度 | **多维度叠加** | 多维度高度叠加 |

> 🔑 **核心秘诀**：PPT 做的不是排版，是说服力。但排版太差会毁掉说服力——客户看到排版混乱的 PPT，心理上先扣 20 分。Skill 帮你搞定排版（消除减分项），你的脑子留给最重要的——怎么说服客户（创造加分项）。

> ⚠️ **避坑指南**：见过有人用一个「通用风格」做所有 PPT——公司周报用科幻风、投资人演示用可爱风、学术报告用夜店霓虹风——那是灾难。

## 2. 四步流水线详解

### 2.1 完整链路

```
Markdown 大纲
  ↓ Step 1: 解析为幻灯片结构
  [每 ## 标题 → 一页幻灯片]
  ↓ Step 2: 选择模板
  [从 16 种设计模板中匹配场景]
  ↓ Step 3: HTML 渲染
  [CDP 浏览器渲染每页为高分辨率图片]
  ↓ Step 4: 导出
  [导出为 PPTX 或 PDF]
```

### 2.2 Step 1：解析 Markdown → 幻灯片结构

```
输入 Markdown：
  # 融资路演：AI 写作助手
  ## 市场机会
  - 全球内容营销市场 $412B
  - AI 写作渗透率仅 3%
  ## 产品方案
  - AI 驱动的长文生成
  - 支持 30+ 语言
  ## 商业模式
  - SaaS 订阅：$29/月
  - 已有 5,000 付费用户

解析结果：
  Slide 1（封面）: 融资路演：AI 写作助手
  Slide 2: 市场机会
    - 全球内容营销市场 $412B
    - AI 写作渗透率仅 3%
  Slide 3: 产品方案
    - AI 驱动的长文生成
    - 支持 30+ 语言
  Slide 4: 商业模式
    - SaaS 订阅：$29/月
    - 已有 5,000 付费用户
  Slide 5（CTA）: 联系我们 + 下一步

规则：
  → H1（#）→ 封面页（封面模板）
  → H2（##）→ 内容页（各一张幻灯片）
  → 每页内容自动分到对应的文本区域
```

### 2.3 Step 2：16 种模板的场景匹配

16 种模板按四大场景分类——不是随便选，而是精准匹配：

| 场景 | 模板示例 | 风格特征 | 适合什么 |
|------|---------|---------|---------|
| **技术/科技** | blueprint, cyberpunk, minimal-dark | 科技蓝、暗色、代码感 | SaaS 路演、技术方案、黑客松 |
| **教育/学术** | academic, chalkboard, sketch-notes | 清晰白底、黑板风、手绘 | 课程、学术报告、知识分享 |
| **商务/企业** | corporate, professional, consulting | 稳重蓝灰、专业字体 | 融资路演、企业汇报、竞标 |
| **生活/创意** | watercolor, creative-soft, gradient-purple | 温暖柔和、色彩丰富 | 生活分享、文创展示、时尚 |

**场景匹配逻辑**：

```
用户说：「我要做一个融资路演的 PPT」
  → 场景 = 商务/企业
  → 推荐模板：corporate（专业稳重）或 consulting（咨询风格）
  → 自动应用：深蓝配色 + 大标题 + 数据可视化布局

用户说：「我要做一个面向学生的课程 PPT」
  → 场景 = 教育/学术
  → 推荐模板：academic（清晰规范）或 sketch-notes（手绘亲和）
  → 自动应用：白底 + 学院风配色 + 结构化信息层级
```

### 2.4 Step 3：HTML 渲染

```
Skill 将幻灯片结构 + 模板样式 → HTML（HTML：网页标记语言） 页面
HTML 页面在 CDP（CDP：Chrome 开发者工具协议） 浏览器中渲染 → 每页截图为高分辨率图片（1920×1080）

为什么用 HTML 而不是直接生成 PPT？
  → HTML 渲染效果精确可控（CSS（CSS：网页样式语言） 精确控制每个像素）
  → 模板即 HTML/CSS 代码（设计师可以直接修改样式）
  → 跨平台一致（同一份 HTML 在任何浏览器中渲染一致）
```

### 2.5 Step 4：多格式导出

```
PPTX 导出：
  → 每张截图嵌入一页幻灯片
  → 可后续在 PowerPoint/Keynote 中编辑文字
  → 适合需要继续修改的场景

PDF 导出：
  → 适合分享和打印
  → 格式锁定，不会因版本/字体问题变形
```

## 3. 自定义设计四维度

### 3.1 模板不是「死」的

用户可以在模板基础上自定义四个维度：

```
1. 纹理（Texture）：
   → 背景纹理：无 / 网格 / 点阵 / 纸张 / 水彩
   → 影响整体质感——加了纸张纹理的 academic 模板有「教科书的质感」

2. 基调（Tone）：
   → 配色基调：暖色调 / 冷色调 / 中性 / 品牌色
   → 同一模板改了基调完全不同——corporate + 暖色调 = 更亲和

3. 字体（Font）：
   → 中文字体：思源黑体 / 思源宋体 / 系统默认
   → 英文搭配字体自动匹配

4. 密度（Density）：
   → 信息密度：高密度（多文字）/ 标准 / 呼吸感（多留白）
   → 融资路演 = 低密度（每页一个核心数字）
   → 学术报告 = 高密度（每页多个数据点）
```

### 3.2 模板 + 自定义 = 无限可能

```
不是 16 种模板 = 16 种 PPT
而是 16 种模板 × 4 个纹理 × 3 个基调 × 2 个字体 × 3 个密度
= 理论上 1,152 种组合

但用户不需要知道这些——Skill 根据场景自动填默认值，用户想调再调
```

## 4. 结构拆解：模板引擎型 Skill 模板（Level 3 预览）

```markdown
## 模板引擎型 Skill 模板

### 核心特征
→ 输入内容 → 选择模板 → 渲染 → 输出成品
→ 多步骤流水线（4+ 步骤）
→ 模板系统 + 场景匹配
→ 支持多格式导出

### 通用结构

## Pipeline（流水线）
Step 1: 内容解析（输入 → 结构化中间表示）
Step 2: 模板匹配（场景关键词 → 最佳模板）
Step 3: 渲染（模板 + 内容 → 可视化输出）
Step 4: 导出（多格式：PPTX/PDF/PNG）

## Template System（模板系统）
- 模板分类（按场景：技术/教育/商务/创意）
- 每类 2-5 个模板
- 场景 → 模板的自动匹配规则

## Customization（自定义）
- 可调维度（纹理/基调/字体/密度）
- 每个维度的默认值
- 自定义不影响模板的核心结构
```

**为什么这是 Level 2→3 的桥梁？**
```
Level 1: 单一步骤或简单调用（压缩图片、转换格式）
Level 2: 2-3 步 + 简单分支（多后端选择、双模路由）
L2-14:   4 步 + 16 种模板匹配 ← 这是 Level 3 的复杂度
Level 3: 5-7 步 + 多决策树 + references 矩阵
```

## 5. 电商案例：电商品牌融资路演 PPT 自动生成

> 🛒 **实战案例**：某 DTC 宠物食品品牌准备融 A 轮（目标 ¥3,000 万），创始人需要在 3 天内准备好路演 PPT 去见 5 家 VC。核心信息都有——月 GMV ¥180 万、复购率 47%、毛利率 62%、30 万私域用户——但创始人从来没做过融资 PPT，不知道路演 PPT 该放什么、不该放什么、数据怎么讲才有说服力。花 ¥8,000 找 FA 代写要等 5 天，来不及。
>
> **用 Slide Deck Skill 从零生成融资路演 PPT**：
>
> | 幻灯片页 | 内容 | Skill 的生成逻辑 | 关键数据 |
> |---------|------|---------------|---------|
> | Slide 1: Hook | 「中国宠物食品市场 2026 年规模 ¥2,800 亿——但 78% 的猫粮蛋白质含量不足 30%」 | 自动从输入数据中提取最具冲击力的对比数字作为开场钩子 | 市场规模 + 行业痛点 |
> | Slide 2: Problem | 传统膨化粮的 3 大问题（高温破坏营养、肉含量虚标、添加剂过量） | 将创始人输入的产品差异点反向推导出行业痛点 | 引用了 3 份第三方检测报告 |
> | Slide 3: Solution | 「低温烘焙工艺 + 85% 鲜肉含量 + 每批次 SGS 检测」 | 提取产品核心差异化数据，转化为价值主张 | 鲜肉含量 85% vs 行业平均 30% |
> | Slide 4: Traction | 月 GMV、复购率、客单价、私域规模 | 自动格式化数据，用柱状图展示 12 个月增长曲线 | 月 GMV ¥180 万（MoM 增长 22%） |
> | Slide 5: Unit Economics | CAC（CAC：客户获取成本） ¥35 / LTV（LTV：用户生命周期价值） ¥680 / 回本周期 21 天 | 从原始数据推算单客经济模型 | LTV:CAC = 19.4:1 |
> | Slide 6: Market | TAM ¥2,800 亿 / SAM ¥420 亿 / SOM ¥8 亿 | 从市场报告中提取分层市场数据 | 品类年增速 34% |
> | Slide 7: Ask & Use of Funds | 「融资 ¥3,000 万，用于供应链扩建 40%、研发 30%、市场 30%」 | 结构化展示资金用途 | 预计 18 个月达到盈亏平衡 |
>
> **模板选择**：自动匹配 corporate 模板（深蓝配色 + 大数字突出 + 数据可视化优先），适合 VC 语境的专业严肃风格。
>
> **效果**：
> - PPT 制作时间：预计 3 天 → 实际 4 小时（2 小时梳理数据 + 2 小时 Skill 生成和微调）
> - 5 家 VC 中 4 家进入第二轮尽调（vs 行业平均 30% 进入二轮）
> - 2 家给出 TS（Term Sheet），估值比预期高 22%（专业的路演材料 = 更强的议价能力）
> - 省下 FA 代写费 ¥8,000 + 3 天等待期
>
> > 🔑 **启示**：融资路演 PPT 的核心不是「设计好看」——VC（VC：风险投资机构） 一天看 20 个案子，不会因为你配色漂亮就投你。但数据组织混乱、故事讲不清楚的 PPT 会让 VC 在 3 分钟内判断「这个创始人不清楚自己的生意」。Skill 的价值在于：把创始人脑子里散落的数据和洞察，按路演叙事的黄金结构（Hook → Problem → Solution → Traction → Economics → Market → Ask）组织成一条 7 页的说服链。
## 6. 掌握检验

**Q1**：课程中 Markdown 到 PPT 的完整 4 步流水线是什么？
- A) 撰写 → 排版 → 配色 → 保存
- B) 解析为幻灯片结构 → 选择模板 → HTML 渲染 → 导出 PPT/PDF
- C) 上传文件 → AI 分析 → 自动生成 → 下载
- D) 输入文字 → 添加图片 → 调整动画 → 导出视频

**Q2**：为什么 16 种模板对应 16 种场景，而不是做一个「通用模板」？
- A) 为了展示设计能力
- B) 不同场景对幻灯片的期待不同——融资路演需要 pitch 模板（专业严谨），学术报告需要 academic 模板（清晰学术风）
- C) 16 种模板渲染速度更快
- D) 增加 SKILL.md 的篇幅

**Q3**：文姐给美妆客户用 gradient-purple 模板，给 3C 数码客户用 minimal-dark 模板。这体现了什么原则？
- A) 客户说什么就用什么
- B) 模板的本质是「场景匹配」——穿着西装去面试，穿运动服去打球，穿着对才舒服
- C) 所有客户应该用同一个模板以保持品牌一致性
- D) 颜色越丰富越好

**Q4**：为什么本课被称为「Level 2 到 Level 3 的桥梁」？
- A) 因为它的难度刚好在中间
- B) 因为它具备 Level 3 的特征（多步骤流水线 + 决策选择 + references 矩阵），但每个步骤相对简单
- C) 因为它是 Level 2 的最后一课
- D) 因为它需要先修完 Level 3 才能理解

**Q5**：文姐用 Skill 后，PPT 制作时间从 5 小时降到 1 小时。请分析时间省在哪个环节？Skill 帮她做了哪些她以前手动做的事？

**Q6**：课程说「PPT 做的不是排版，是说服力。但排版太差会毁掉说服力。Skill 帮你搞定排版，你的脑子留给最重要的——怎么说服客户。」请解释这句话的含义：为什么排版和说服力是「分工」关系而非「替代」关系？

## 7. 答案

<details>
<summary>点击查看答案</summary>

**Q1**：**B** — 完整链路：Markdown 大纲 → 解析为幻灯片结构（每 `##` 一页）→ 选择模板（从 16 种中匹配场景）→ HTML 渲染（CDP 浏览器）→ 导出为 PPT/PDF。

**Q2**：**B** — 公司周报用科幻风、投资人演示用可爱风、学术报告用夜店霓虹风——都是灾难。场景不同，期待不同：pitch 模板 = 投资人期待的专业严谨；academic 模板 = 学术界期待的清晰规范；creative-soft 模板 = 生活类客户期待的温暖亲和。

**Q3**：**B** — 16 种模板不是为了炫技，而是每种场景对「恰到好处」的定义不同。美妆需要高奢感（gradient-purple），3C 数码需要科技感（minimal-dark），食品需要生活感（creative-soft）。

**Q4**：**B** — Level 2 特征是单一步骤或简单分支。Level 3 特征是多步骤流水线 + 决策树 + references 矩阵。baoyu-slide-deck 有 4 步流水线、16 种模板的决策选择、references 资源，但每步逻辑相对简单——所以是 L2 复杂性上限、L3 复杂性下限。

**Q5**：时间省在：(1) 找模板——原来要浏览几十个 PPT 模板网站挑选，现在 Skill 自动匹配合适模板；(2) 排版——原来每页手动调字体、大小、位置、配色，现在模板自带统一排版；(3) 配图——原来要搜索、下载、裁剪、放置，现在模板内置布局；剩下 1 小时是文姐的「重要工作」：打磨内容逻辑、调整话术、定制行业数据——这些是「说服力」层面的工作，机器无法替代。

**Q6**：排版和说服力是分工关系：(1) 排版是「专业性门槛」——排版差会让客户觉得「这家公司连 PPT 都做不好，能做好我的业务吗？」，直接损害信任；(2) 说服力是「内容竞争力」——数据、逻辑、案例、洞见，这才是让客户说「行，签」的核心；(3) Skill 负责 1（消除负面印象），人负责 2（创造正面说服）——机器消除了「减分项」，人才能把精力集中在「加分项」。两者不是替代，是各司其职。

（5/6 通过）
