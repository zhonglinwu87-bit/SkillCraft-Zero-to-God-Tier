# L4-05：竞品深度侦察 —— 三阶段研究 + 交叉验证 + 快扫/深档 + 数据持久化

> 🎯 **学什么**：学会从竞品URL出发，通过三阶段（站点抓取→SEO数据→综合分析）系统化地生成结构化竞品档案。用交叉验证发现竞品对外宣称与数据事实之间的矛盾，用快扫（Quick Scan）和深档（Deep Profile）两种模式匹配不同场景，用数据持久化规则支持时间维度的对比分析。核心洞察：竞品分析中最难做到的是第四条原则——诚实评估。人的本能是淡化竞品优势、放大竞品弱点，但一份自我欺骗的竞品分析比没有竞品分析更危险。
> 💡 **难易度**：⭐⭐ | ⏱️ **预计时间**：50 分钟

***

## 1. 课程概览

> 💡 **白话小课堂**：这个 Skill 就像一个**商业侦探**——你开了家奶茶店，对面也开了一家。你不只是站在门口看人家的菜单——你点了他家所有产品、数了每天多少顾客进出、看了网上的评价、翻了他们的微信公众号、甚至研究了他家用的是什么奶源和设备。最关键的是，你不会因为"希望对手比我差"而选择性忽略对方比你强的地方——因为诚实的分析才是有用的分析。

> **本课的独特定位**——情报收集型 Skill：

| 特征 | L4-04（社区营销） | L4-05（本课） |
|------|-----------------|-------------|
| 核心问题 | 怎么让用户帮你拉用户 | **怎么把对手看个底朝天** |
| 分析对象 | 你自己的社区 | **竞争对手的产品和策略** |
| 关键原则 | 共享身份定位 | **诚实评估 + 交叉验证** |

> 🔑 **核心秘诀**：三阶段研究法的精髓在于交叉验证——网站说自己"服务10万+企业客户"，但SEO数据显示每月自然流量只有3000。这个"10万"就值得怀疑。网站说的（Phase 1）和数据显示的（Phase 2）互相矛盾时，标注置信度并进一步验证。

> ⚠️ **避坑指南**：定价页是竞品商业策略的"体温计"——变化最快、最有洞察价值。如果竞品每隔一周就调一次定价，说明他们在试探市场定位。

> **来源**：Corey Haines marketingskills（`coreyhaines31/marketingskills --skill competitor-profiling`）

## 2. 竞品分析的四个原则

### 2.1 四项铁律

```
原则1: Facts Over Opinions（事实优于观点）
  → 每一条声明都能追溯到来源
  → 无法确认的信息标注为"[推断]"
  → 示例：❌ "他们的技术架构很落后"
         ✅ "他们仍在使用 PHP 5.6（来源：HTTP响应头），该版本已于2018年停止安全更新"

原则2: Structured and Comparable（结构化且可对比）
  → 所有竞品档案遵循相同模板
  → 一致性比单份档案的完整性更重要
  → 目的：你能把3份竞品档案并排对比，而不是读3份格式完全不同的报告

原则3: Current Data（当前数据）
  → 档案是快照，必须包含生成日期
  → 标记看起来过时的内容："[可能过时——最后更新于2023年Q2]"
  → 定价和功能列表需要最频繁的更新

原则4: Honest Assessment（诚实评估）⚠️ 最难做到
  → 不夸大竞品弱点，不淡化竞品优势
  → 人的本能："希望竞品比我们差" → 不自觉放大弱点、淡化优势
  → 一份自我欺骗的竞品分析让你在错误信息基础上做决策
  → 你以为竞品不行，结果市场被抢了都不知道
  → 诚实承认竞品确实比你好，然后决定怎么应对——这才是正确的态度
```

### 2.2 竞品选择的三层分类

```
Tier 1: 直接竞品（同体量、同客户群）
  → 客户会在这两者之间直接比较
  → 值得做Deep Profile
  → 示例：你是电商SaaS，他们也是电商SaaS，价格差不多

Tier 2: 间接竞品（大厂/跨品类）
  → 客户可能把他们当作替代方案
  → 至少做Quick Scan
  → 示例：你是垂直SaaS，大厂的通用方案也在触达你的客户

Tier 3: 潜在竞品（新进入者/低价搅局者）
  → 目前体量小但增长快
  → 定期Quick Scan监控
  → 示例：刚融了A轮的新团队，产品看起来像你三年前的样子
```

## 3. 三阶段研究流程详解

### 3.1 阶段一：站点抓取

```
抓取页面清单（按重要性排序）：

1. 首页（Homepage）
   → 价值主张是什么？
   → 目标客户是谁？（从措辞和案例判断）
   → 社会证明有多强？（客户Logo、数据、评价）

2. 定价页（Pricing）⚠️ 优先追踪
   → 方案层数？（通常3-4层最佳）
   → 价格区间？（最低/最高）
   → 计费方式？（按月/年/用量/坐席）
   → 免费版/试用版策略？
   → 为什么优先？定价页变化最快，是竞品商业策略的"体温计"

3. 功能页（Features/Product）
   → 核心功能有哪些？
   → 差异化功能是什么？
   → 用了什么语言描述功能？（可对比你的文案）

4. 客户案例/评价页（Customers/Reviews）
   → 主要服务哪些行业/规模？
   → 客户说的最多的是什么？（好话和坏话都看）
   → 哪些客户你可能也认识/可以联系验证？

5. 关于页/招聘页（About/Careers）
   → 团队规模？（从招聘岗位数量反推）
   → 正在招什么人？（扩张方向=战略意图）
   → 融资情况？

6. 更新日志/博客（Changelog/Blog）
   → 发布频率？（每周/每月/不定期）
   → 产品方向？（最近在开发什么？）
   → 内容策略？（写什么话题？频率？质量？）
```

### 3.2 阶段二：SEO与市场数据

```
数据源和核心指标：

SEO数据（如DataForSEO/Semrush/Ahrefs）：
  → 域名权重（Domain Rating / DR）：整体权威度
  → 外部链接域名数（refdomains）：多少个独立网站链接到他们
  → 月自然流量估算：从排名关键词估算
  → 最高流量页面：什么内容类型在给他们带流量？
  → 关键词排名：排什么词？排名位置？

交叉验证示例：
  竞品A官网宣称："服务30万商家"
  SEO数据显示：refdomains仅820个（同等体量SaaS公司均值2000+）
  → 结论：这个"30万"可能严重注水
  → 标注：[置信度低——SEO数据与宣称不匹配，建议进一步验证]

  竞品B官网：产品描述强调"企业级安全"
  SEO数据：排名大量"免费XX工具""XX破解版"类关键词
  → 发现：他们可能在通过灰色关键词获取流量
  → 洞察：其品牌定位和流量获取策略之间存在矛盾
```

### 3.3 阶段三：综合分析报告

```
竞品档案的8个组成部分：

1. At a Glance（一页概览）：公司名、URL、成立时间、融资阶段、团队规模估计
2. Positioning（定位）：价值主张、目标客户、品牌语调
3. Product（产品）：核心功能矩阵、差异化功能
4. Pricing（定价）：方案结构、价格、计费方式
5. Marketing（营销）：获客渠道、内容策略、SEO表现
6. Customers（客户）：目标行业、典型规模、评价汇总
7. SWOT（优劣势）：相对于你的优势和劣势
8. Competitive Implications（战略启示）⚠️ 最重要——直接转化为行动
   → 不是摆事实，而是回答"基于以上分析，你该怎么应对？"
   → 每一条启示都应该是可执行的行动建议
   → 示例："竞品A的定价比你低30%——要么降低入门价吸引价格敏感用户，
     要么强化差异化（他们的客服响应时间是48小时，你的是2小时）"
```

## 4. Quick Scan vs Deep Profile

### 4.1 两种模式的适用场景

```
Quick Scan（快扫——10分钟级）：
  适用场景：
    → 竞品数量超过10个，需要快速过一遍
    → 季度例行竞品回顾
    → 新出现的小型创业公司
  做法：
    → 抓取3-5个关键页面（首页/定价/功能/评论）
    → 获取3个核心SEO指标（DR/流量/排名关键词）
    → 输出缩略档案：At a Glance + Positioning + Pricing + 3条战略启示

Deep Profile（深档——数小时级）：
  适用场景：
    → 竞品对你的核心业务构成直接且重大威胁
    → 准备进入一个新市场，需要全面了解已有玩家
    → 融资/战略决策前的竞品全景分析
  做法：
    → 抓取10+个页面（包括所有子页面、博客、招聘页）
    → 完整SEO数据+内容策略分析+技术栈分析
    → 输出完整档案：8个组成部分全部覆盖
```

### 4.2 数据持久化规则

```
铁律：永远创建新日期文件夹，不覆盖旧数据

原因：
  → 每次抓取都是独立的快照
  → 三个月后能回溯："他们这次调价了，上次定价是什么来着？"
  → 如果覆盖了旧数据，这个答案就永远丢了

文件夹结构：
  raw/YYYY-MM-DD/           ← 每次抓取存新文件夹
    ├── homepage.md         ← 首页内容的markdown保存
    ├── pricing.md          ← 定价页
    ├── features.md         ← 功能页
    ├── seo-data.csv        ← SEO数据导出
    └── notes.md            ← 当时的观察和标注

三个月后：
  raw/2024-03-15/  vs  raw/2024-06-15/
  → diff对比 → 发现3个关键变化 → 更新档案
```

## 5. 多竞品并行处理策略

```
当同时侦察3+个竞品时：

第一轮：并行抓取所有竞品的首页+定价页
  → 定价页是最重要的优先级（变化最快）
  → 首页提供定位和品牌语调

第二轮：深入各竞品的功能页+博客+案例
  → 此时应该已经对每个竞品有了初步画像
  → 功能页关注差异化（他们强调什么？你强调什么？）

第三轮：SEO数据交叉验证
  → 对比各竞品的网站宣称 vs 数据事实
  → 发现矛盾 → 标注置信度

第四轮：生成档案+横向对比
  → 所有档案用同一模板 → 可并排对比
  → 提炼战略启示（不只描述，而是建议怎么应对）
```

## 6. 结构拆解：情报收集型 Skill 模板

```markdown
## 情报收集型 Skill 模板

### 核心特征
→ 数据来源 = 多源交叉验证（网站抓取 + SEO数据 + 评测/招聘/社交媒体）
→ 关键设计 = 三阶段 → 标准化档案模板 → 诚实评估
→ 核心价值 = 不只是"描述竞品"，而是"告诉你该怎么做"

### 通用结构

## Research Principles（研究原则）
1. Facts Over Opinions（可溯源+标注推断）
2. Structured and Comparable（统一模板）
3. Current Data（档案=快照，含生成日期）
4. Honest Assessment（不淡化优势/不夸大弱点）

## Three-Phase Research（三阶段研究）
Phase 1: 站点抓取（首页/定价/功能/案例/关于/更新日志）
Phase 2: SEO数据（DR/refdomains/流量/关键词/交叉验证）
Phase 3: 综合报告（8部分档案 → 战略启示驱动行动）

## Two Modes（两种模式）
Quick Scan: 10+竞品 / 例行回顾 / 新进入者 → 抓取3-5页+3个SEO指标
Deep Profile: 直接威胁 / 战略决策 → 全量抓取+完整8部分档案

## Data Persistence（数据持久化）
raw/YYYY-MM-DD/ + never overwrite → 支持时间维度diff对比
```

## 7. 电商案例：抖音女装赛道TOP5竞品全维度侦察

> 🛒 **实战案例**：某抖音女装白牌商家，主营通勤风女装（客单价¥189-¥399），月GMV约¥200万但增长停滞。团队不知道竞品在做什么——只知道"她们卖得不错"，但不知道为什么不错。决定对女装赛道TOP5竞品进行全维度侦察。

**竞品选择（三层分类）**：

| 层级 | 竞品 | 月GMV估算 | 客单价 | 粉丝数 | 选择原因 |
|------|------|:--------:|:-----:|:-----:|---------|
| Tier 1 直接竞品 | 竞品A（风格重叠90%） | ¥380万 | ¥199-¥399 | 62万 | 同风格、同价位、客户直接对比 |
| Tier 1 直接竞品 | 竞品B（风格重叠70%） | ¥520万 | ¥159-¥349 | 108万 | 相似风格但体量更大，学习对象 |
| Tier 2 间接竞品 | 竞品C（快时尚大店） | ¥1200万 | ¥79-¥199 | 280万 | 价格带低一档但抢走价格敏感用户 |
| Tier 2 间接竞品 | 竞品D（高端通勤） | ¥890万 | ¥399-¥899 | 45万 | 价格带高一档，参考溢价策略 |
| Tier 3 潜在竞品 | 竞品E（新锐品牌） | ¥85万 | ¥249-¥399 | 8万 | 3个月从¥15万涨到¥85万，增长迅猛 |

**六维度侦察结果**：

| 维度 | 竞品A | 竞品B | 竞品C | 竞品D | 竞品E |
|------|-------|-------|-------|-------|-------|
| 定价策略 | 每周一新品上架时调高¥20，周末降价 | 固定定价，靠满减活动拉动 | 爆款¥99引流，搭配款¥199收割 | 锚定高端定位，不打折 | 上新首周9折→恢复正价 |
| 流量来源 | 短视频70%+直播30% | 直播60%+付费投流40% | 付费投流55%+直播35%+短视频10% | 短视频80%（质感内容） | 短视频50%+达人种草50% |
| 内容策略 | 日更3条（穿搭变装+通勤场景），高清精修 | 日更5条（直播切片为主），生产效率>质量 | 日更8条（工厂实拍+价格对比），走量策略 | 日更1条（电影质感短片），少而精 | 日更2条（素人试穿+设计师讲解），差异化 |
| 评价分析 | 好评集中在"版型好"（47%），差评集中在"色差"（28%） | 好评集中在"性价比高"（52%），差评集中在"面料薄"（31%） | 好评集中在"便宜"（62%），差评集中在"版型差"（38%） | 好评集中在"质感好"（58%） | 好评集中在"设计独特"（44%） |
| 直播策略 | 每晚8-12点，1位主播，场观3,000-8,000，GPM ¥1,500 | 每天两场（14-18点+20-24点），3主播轮换，GPM ¥2,100 | 全天16小时轮播，素人主播，GPM ¥680 | 每周直播3次，场景布置精致，GPM ¥3,200 | 每周直播5次，创始人亲自上阵，GPM ¥1,100 |
| 供应链 | 广州沙河档口拿货+自有改版（7天上新） | 杭州意法档口+代工厂ODM（5天上新） | 义乌工厂直供（3天上新，库存深） | 自建供应链，韩国面料进口（15天上新） | 设计师品牌工作室（10天上新，量少） |

**交叉验证发现的矛盾**：
- 竞品A宣称"每周上新20款"但抖音店铺实际周上新仅8-12款（内容标注"每周上新"但数据打脸）
- 竞品C直播间显示"已售10万+"但评价仅2,300条（退货率高或刷单嫌疑——正常女装评价率3-5%，该店仅0.23%）
- 竞品E粉丝仅8万但月GMV ¥85万——极高粉丝价值（¥10.6/粉丝/月），说明内容转化效率极高

**战略启示**：
1. 竞品B的GPM ¥2,100是行业标杆——重点研究其直播话术结构和排品节奏（每5分钟一个款，爆款+利润款交替），而非只看选品
2. 竞品C的低价策略正在被供应链优势放大——不要在¥99以下价格带跟他们打价格战，没胜算
3. 竞品E是最高危的——用内容差异化（设计师讲解+素人试穿）在3个月内翻了5.7倍，且粉丝价值极高。最值得做Deep Profile追踪
4. 你的优势空间在"版型+面料"——所有竞品的差评集中在色差和面料（品类通用痛点），如果你能解决"所见即所得"问题，定价可以比竞品A高¥30-50而不影响转化

> 🔑 **启示**：竞品侦察的价值不在"知道他们在做什么"，而在"知道他们做什么做得好但没做全"——比如竞品B直播强但短视频弱，竞品D内容精但上新慢。找到竞品的"战略性放弃"，就是你差异化切入的机会。

## 8. 掌握检验

**Q1**：竞品分析的四个原则中，哪一条最难做到？为什么一份"自我欺骗"的竞品分析比没有竞品分析更危险？
- A) Facts Over Opinions（事实优于观点）
- B) Structured and Comparable（结构化且可对比）
- C) Current Data（当前数据）
- D) Honest Assessment（诚实评估）

**Q2**：三阶段研究流程中，Phase 1（站点抓取）和Phase 2（SEO数据）如何通过交叉验证发现矛盾？请举一个课程中的具体例子。

**Q3**：为什么数据持久化要求"永远创建新日期文件夹，不覆盖旧数据"？

**Q4**：以下哪种情况应该选择 Deep Profile 而非 Quick Scan？
- A) 竞品数量超过10个
- B) 竞品对你的核心业务构成直接且重大威胁
- C) 只是做季度例行竞品回顾
- D) 竞品是新出现的小型创业公司

**Q5**：多竞品并行处理时，为什么"定价页"应该优先追踪？定价页变化快能反映什么信号？

**Q6**：竞品档案文档的8个组成部分中，哪个部分直接将分析转化为行动？请简要说明该部分的作用。

**Q7**：请设计一个简易的Quick Scan竞品分析计划：选定一个你熟悉的竞品，列出你要抓取的3-5个关键页面，以及你要从SEO数据中获取的3个核心指标。

## 9. 答案

<details>
<summary>点击查看答案</summary>

**Q1**：**D** — 诚实评估最难做到。人的本能是淡化竞品优势、放大竞品弱点。一份自我欺骗的竞品分析让你在错误信息基础上做决策——你以为竞品不行，结果市场被抢了都不知道。诚实承认竞品确实比你好，然后决定怎么应对，这才是正确的态度。

**Q2**：参考答案 — 课程案例中，竞品A官网宣称"服务30万商家"，但SEO数据（DataForSEO）显示其外部链接数（refdomains）仅820个，远低于同等体量SaaS公司的均值2000+。这个"30万"可能严重注水。这就是交叉验证：网站说的（Phase 1）和数据显示的（Phase 2）互相矛盾，需要标注置信度并进一步验证。

**Q3**：参考答案 — 不做覆盖、只做叠加，是为了支持不同时间快照的对比（diff）。比如三个月后能回溯"他们这次调价了，上次定价是什么来着？"如果覆盖了旧数据，这个答案就永远丢了。每次抓取都是独立的快照。

**Q4**：**B** — 当竞品对你核心业务构成直接且重大威胁时，值得做Deep Profile。A、C、D都是Quick Scan的适用场景。

**Q5**：参考答案 — 定价页变化最快，它是竞品商业策略的"体温计"。如果竞品频繁调价，说明他们在试探市场定位；如果定价三个月没变，说明找到了稳定的定位。优先追踪定价页可以最早发现竞品的战略意图变化。

**Q6**：参考答案 — "Competitive Implications（战略启示）"直接转化为行动。它回答"基于以上分析，你该怎么应对？"——需要列出具体的行动建议，而不只是摆事实。

**Q7**：参考答案 —
- 抓取页面：首页（价值主张+CTA+社会证明）、定价页（方案层数+价格+计费方式）、功能页（核心能力+差异化）、Changelog页（发布速度+产品方向）
- SEO指标：域名权重(DR)、月自然流量估算、最高流量页面内容类型
- 输出：缩略档案，包含At a Glance + Positioning + Pricing + 3条战略启示

**评分**：答对 5/7 = 通过。
