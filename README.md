## 使用方式

本仓库是 Obsidian vault 的一部分，所有笔记均为 Markdown 格式，支持：

- **Obsidian 原生打开**：用 Obsidian 打开本目录即可作为独立知识库使用
- **任意 Markdown 编辑器**：Typora、VS Code、Notion 等均可直接阅读
- **Wiki-link 格式**：笔记间通过 `[[双向链接]]` 互联，形成知识网络
